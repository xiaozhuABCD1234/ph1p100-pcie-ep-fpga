# 调试分析归档

这些文档是 2026-10-29 的只读分析结论，不是当前构建入口，也不代表已上板验证。

| 文件 | 主题 | 关键结论 |
|---|---|---|
| `sync_b_debug.md` | B 路不出 SOF | B 的 I2C 正常；故障在 B 传感器→MIPI/CSI，最可能是 slave 模式缺 A 的 XVS/XHS；给出 0x84/0x128 判读与最小补丁 |
| `writer4k_debug.md` | 4K writer `p_bad` | `0xF4=0x01` 最可能是超预算钳位；4K 物理原点是 (12,16)，`X0=0/SKIP_ROWS=37` 几何不自洽；给出 0x80/0xD0 判读 |

引用寄存器/行号以文档写作时的 RTL 为准；改代码后需重新核对。
