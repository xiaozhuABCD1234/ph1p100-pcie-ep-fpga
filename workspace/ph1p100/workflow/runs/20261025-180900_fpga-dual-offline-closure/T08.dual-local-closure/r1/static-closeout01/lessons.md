# Static closeout lessons

- Registered descriptor presentation needs a lifetime tied to ownership and consumer mode, including simultaneous mode change/publication. A local stall fix can leave a stale valid offer when ownership is later released.
- Thirteen passing local scenarios and genuine arrival/read overlap do not close a statically identifiable untested ownership path. Freeze blocked when further implementation is necessary and current permission is metadata-only.
- Count wrappers and nested operations conservatively. Preserve old overruns, the uncompleted timely handoff and unavailable shell-session evidence rather than backdating a new freeze.
