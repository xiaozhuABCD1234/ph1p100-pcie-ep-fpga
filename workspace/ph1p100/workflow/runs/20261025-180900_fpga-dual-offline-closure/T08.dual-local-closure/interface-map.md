# T08 isolated dual local candidate

The candidate derives from the planning-manifest frozen production RAW top. DUAL_LOCAL_EN defaults to zero. When enabled, A and B writer CLOSEDLOOP_EN are both set; their DHI publication pulses enter separate two-slot mailboxes. The old pusher and the debug automatic third-frame abort are disabled only in this branch.

All descriptor, release, consumer_mode/epoch and external native AXI ports operate in w_ddr_dhi_clk, with the same common DDR reset as the writers. consumer_epoch must be stable during a session and change after common reset. a_desc/b_desc fields exactly follow the run guide: camera_id/slot_id, epoch/session/capture_seq, base/dma_bytes/raw_bytes, width/height/bayer_phase. Transfer occurs only on valid and ready; fields remain held while stalled. Mode 2 exports these streams to an external encoder; no T10 candidate is merged here.

Mode 1 selects the local CRC reader and alternates cameras at frame boundaries when both have work. Mode 2 selects ext_ar/ext_r exclusively. Mode 0 disables reads and safely retains slots. Runtime mode changes are accepted only when all slots are free and AR/R are empty; active changes increment reject_count. rel valid/ready in mode2 matches the complete held identity and rejects stale, duplicate or unsupported status. Status0 additionally requires the complete DMA read count; status1 requires no outstanding read; status2 requires no read. rel_camera selects the writer and rel_slot its single-cycle cl_release bit. No consumer reset is used to conceal an in-flight DDR transaction.

The local reader retains the existing CRC/checking core and adds descriptor/header camera, session (word4), capture_seq, geometry, RAW length and phase checks plus zero tail checks. Its registered AR skid and outstanding beat counter retain ownership through checker abort/timeout. Accepted reads drain before release. Permanently absent AR/R progress enters LOCK and retains slots until common DDR reset.

sync_skew/seq_a/seq_b/miss_a/miss_b/relock/timestamp are exported directly in the existing tl_clk_user 50 MHz observation domain. They are not sampled as multi-bit asynchronous DHI data. Source SOFs retain sync_sof_mailbox crossings. Header timestamp fields stay zero. The observations describe digital SOF pairing, not measured sensor exposure.

sync_i2c_config is a named wrapper around the b10 clock-enable ui_i2c. It preserves the exact b10 read_mask function and 200000-cycle transaction deadline, writes the mode1 table with only safe standby/stop/Hi-Z overrides, reads all masked entries, then hands the same real core exclusively to sync_start_ctrl. AE cannot preempt it; automatic CANCEL_STANDBY/START_MASTER are absent from this branch. The old default configuration branch remains present.

Environment boundaries: vendor_env models PLL/PCIe idle behavior and a 256-bit native AXI DDR memory with real AW/W/B and AR/R handshakes. sensor_i2c uses only SCL/SDA and a separate register memory, including random reads and final master NACK. MIPI_PHY_SIM_STUB bypasses the physical PHY only; checked packet validation, unpacker, writers, CRC, arbiter, sync controller and real ui_i2c remain RTL. Small W8H2 cases do not establish full-size frame rate or physical behavior.

Reproduction uses run_t08.py compile/case, or run_local.py with an explicit finite case list. Each native child has a 300-second deadline; termination targets only the owned PID tree. Every test output is isolated. sources.f and integration-sources.tcl are existence-checked source integration entries and invoke no TD build. G2/3/4 remain not_run; hardware and production migration need a later authorized run. Rollback is to stop using this candidate; no production input was changed.
