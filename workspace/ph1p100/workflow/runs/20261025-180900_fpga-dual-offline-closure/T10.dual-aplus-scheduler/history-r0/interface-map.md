# T10 isolated candidate interface and source closure

This directory is an offline source candidate, not a production or hardware replacement. `sources.f` and `integration-sources.tcl` name only the three candidate RTL files. Both frozen `a1_frame_top.v` and `a1_deflate_core.v` are byte-identical to their planning inputs. No TD commands have run.

`dual_aplus_scheduler.sv` uses one DHI/consumer clock. Each `a_desc_*` / `b_desc_*` input has two physical-slot mailboxes. A transfer is valid && ready; ownership persists after selection until the complete `rel_*` record is accepted. Slot mailboxes hold the complete camera/slot/epoch/session/capture_seq, base, lengths, geometry and phase. Basic mismatches and insufficient CMP capacity reject with status2 before AR. R10F/header/data errors reject with status1 after outstanding traffic drains. `rel_*` is the consumer's output; the upstream publisher must independently match the returned complete identity before pulsing a writer release. There is no upstream release validation adapter in this package. Descriptors already owning a physical slot are backpressured.

The native AXI read port uses 29-bit byte addresses, id3, ARLEN0, ARSIZE5, INCR. Every transfer is one 32-byte beat and at most one is outstanding. A 64-byte reservoir handles continuous 5-byte groups across 32-byte boundaries and simultaneous take/refill. Header128 and DMA zero padding never enter the codec. Four header reads precede data reads. Headers are CRC checked with bytes88..91 zeroed. Identity, geometry, packed format, raw/payload CRC equality, flags and reserved bytes are checked. Payload CRC is calculated while reading; the last compressed word cannot commit before complete DMA/tail verification. Addresses must exactly match the declared camera/slot base and lengths must match the elaborated geometry. Default bases are 0x00100000/0x00900000/0x01100000/0x01900000. HDR timestamp fields are passed only as unknown metadata; no exposure claim is made.

Two CMP byte-memory sinks reserve a slot before reading RAW. States are FREE/WRITING/READY/READING. `cmp_valid && cmp_ready` exports metadata and enters READING; `ack_valid` frees only a READING slot with exact source identity and CMP slot. Incorrect or duplicate ACK increments `reject_acks`. `cmp_read_slot/addr/data` provides byte access to held memory. These are behavioral local sink handshakes, not RK or PCIe acknowledgements. Default capacity is 8MiB per sink; simulation uses a declared worst-stored bound plus margin and a separate capacity-rejection case.

`abort` stops new requests but never withdraws an asserted AR. Accepted AR is drained before release. Permanent response absence enters LOCK, preserving RAW/CMP reservation until common DDR reset; the TB explicitly clears its response queue at the same reset. The codec has a separate registered cleanup reset after a safely drained failure. This reset clears its sticky abort and held killed output; it does not reset the reader/mailboxes or conceal outstanding AXI traffic. Frozen core RTL is unchanged. Invalid RID/RLAST conservatively LOCKs; these categories are not yet explicitly tested.

The source uses fixed slot priority within each camera and frame round-robin between cameras. A full per-camera arrival-order FIFO and duplicate capture-sequence history rejection are not implemented; a tester/planner must judge whether the frozen mailbox contract requires them. There is no pulse-publication adapter here: this package starts at the ready/valid description interface, and the independent source model holds valid until accepted.

Environment substitutions are limited to independent descriptor publication, a native single-beat DDR response model, deterministic packed RAW10 source bytes/header vectors, and local CMP ACK/dump behavior. The real frame transform and deflate kernel are compiled and simulated. No physical DDR, vendor CSI, PCIe, timing constraints, IP synthesis, STA/physical CDC, resources or hardware performance has been exercised. All reset/CDC reasoning is limited to this single-clock module and testbench.
