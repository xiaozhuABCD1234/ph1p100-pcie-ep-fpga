# Delivery lessons

Reserve an exposed descriptor identity across backpressure; unrelated ACK/recommit must not reprioritize it. Use legal public traffic and real encoder completion for both old counterexample and corrected matrix.

A completed result file is not a frozen delivery. After an external capacity interruption, bind exact compiled inputs, captures, controls, actual time and author stop flags in a separate static-only directory. Never rerun exhausted cases merely to regenerate metadata.

Recover visible tool history from actual context, while preserving terminal/API boundary unknowns. Command journal row counts establish compile/case processes, not total tool calls. Preserve old deadlines and manifests rather than backdating the new delivery.
