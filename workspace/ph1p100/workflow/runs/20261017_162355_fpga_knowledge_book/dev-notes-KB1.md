## 7. Lessons（可复用）

- **L1**：B 站（bilibili）视频页在子会话的联网抓取**不可稳定用于"标题一致性"核验**（同一链接多次请求返回不同结果/无关标题）。登记视频类资源时优先换可稳定读标题的载体；B 站条目一律按"无法在线核验+精确检索词"降级，**不得**沿用历史会话的"已核验"状态。
- **L2**：`_写作规范.md` 对"项目文件引用"要求可解析路径；写作时**首次出现即写项目根相对全路径**，后续同文件可简写——首版裸文件名会被路径扫描判为不可解析。
- **L3**：Path-scan 要做到"围栏感知"，并把"模板占位（`../文件名.md`）、根相对写法、通配符、`:行号` 后缀、寄存器表达式（`dly_pdata[*]`）"分类处置，否则误报淹没有效信号。
- **L4（重复警告仍成立）**：对长文档做字符串替换时，"仅差一个换行/引号变体"的最小差编辑极易误删或错位；本包 r0/r1 共发生 3 次同类险情（2 次换行、1 次引号变体），全部靠**行数/LF 计数＋定点复核**及时修复。建议：替换后立即做一次 LF/行数与关键锚复核；高风险文本改用逐字节工具（PowerShell 字面替换/写行）执行。
- **L5**：对"是否越权写文件"要**当天纠偏**：误建的临时脚本按项目规则以"单文件明确路径"删除，并把扫描改为内联执行，避免在 run 目录留下未声明的产物。
- **L6（r1）**：引用政府/知识库类条目要核对**重定向终局**：`/wiki/先进先出` 实际落到会计条目（与"先进先出算法"是两回事）——登记与章节链接都应取**目标条目本身的 URL**，而不是自然语言词名。
- **L7（r1）**：测试者发现的"记录级不一致"（汇总算式、共用声明、脚注归属、自检字节数）与"事实级错误"（guard/nominal 计数）要区别对待：前者最小面改记录并在版本记录留痕；后者必须回读到**证据 JSON 原文**再改，并补一个正例（002820）避免"只换反例"。
