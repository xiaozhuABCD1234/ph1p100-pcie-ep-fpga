# fpga-design-guide — 知识书内容与格式约定（run 20261017_162355_fpga_knowledge_book）

- 本文件=本次任务的"工程约定"：纯文档任务，无 RTL/时序/接口电平对象；冻结的是**内容规范、结构规范、来源与核验规则、事实分级与禁止写法**。通用 RTL 语义（页/帧/压缩/PCIe 等）见 `.agents/skills/fpga-design-guide/SKILL.md`，本任务不重复冻结。
- 适用：本 run 全部工作包（KB0–KBZ）的开发与三个测试维度。变更本文件=范围变更，须回规划者。

- 编码 UTF-8（无 BOM）；换行 LF；Markdown（GFM）；文中链接使用相对路径引用项目文件（从 `docs/知识书/` 出发，如 `../DeepSeek独立检测与现行方案整合_2026-10-16.md`）。

## 2. 章节模板（每章必含节，冻结）

1. `## 10 分钟速读卡`：本质一句话 / 为什么重要 / 本项目怎么用 / 一个记忆锚。
2. `## 本章要回答的问题`：3–6 条编号问题。
3. 正文小节（`##`/`###`，由浅入深：直觉 → 原理 → 数字/公式 → 硬件实现视角 → 本项目实例），必须按此渐进顺序组织；首次出现术语须先给白话定义。
4. `## 与本项目方案的对应`：表格化（结论｜依据：项目文件路径或【通用原理】）。
5. `## 决策点与判决框架`（有则必写）：选项/权衡维度/当前选择及理由/何时应重开（触发条件）。
6. `## 常见误区`：≥3 条。
7. `## 自测题`：≥5 条；答案紧随本节之后（`<details>` 折叠或"参考答案"小节均可）。
8. `## 延伸资源`：表格，字段=`标题｜类型(视频/文档/论文)｜语言｜体量(时长/页数)｜推荐理由(≤40字)｜链接｜核验状态｜备用检索词`。
9. `## 术语增量`：本章新增术语（用于 KBZ 汇总）。
10. `## 版本记录`：初稿/修订轮次+一句变化。

- 每章建议篇幅 120–350 行；不为凑量注水；单章自洽（可独立阅读），跨章引用只写"见第 N 章"。

## 3. 事实分级与禁止写法（冻结）

- 三个显式标记（用到即标）：
  - 【本项目事实】= 能指向项目文件/证据的陈述（须同时给路径；数字须与来源一致）；
  - 【通用原理】= 来自公认外部资料的技术陈述（延展资源表内给来源）；
  - 【设计候选】【待验证】【未决】= 尚未实现/未板验/未拍板的方案或口径。
- 禁止：
  - 把设计候选、配置值、需求计算写成"已实测/已通过"（含四舍五入式含糊）；仿真/软件/离线结果不得写作硬件通过；
  - 把组织方口径写成已批准（JPEG/LZ77 替代问题=未决）；把队友/用户未确认事项写成已承诺；
  - 引用不存在的文件路径；引用未实际核对的外部链接（核验规则见 §5）；
  - 大段复制外部资料（单处引用≤2 句，且注明来源）；复制项目文档大段正文（改为路径引用）。
- 数字基准（写作允许引用，一致性验收范围）：155.520/194.400 MB/s、2,592,768B、128B/640B/三层 CRC、2,073,600 样本、77/150/29、1 2 1/2 4 2/1 2 1、1333/1600/800 的 CK 666.67/800/400MHz、CL/CWL 示例值（E=6/5、J=10/7、K=11/8——作答时必须关联 JEDEC 表述"速度等级（speed bin）"且注明"具体以所选颗粒/控制器参数为准"）。

## 4. 全书大纲边界（冻结）

- KB0 转录 dev-plan §3 的 27 章+3 附录；**章数量、章主题、Part 划分不得改**；章内小节的取舍自由，但不得把别章主题大幅写入本章（交叉处只做"见第 N 章"）。
- 每章固定按"P0 底座 → P1 采集 → P2 存储与带宽 → P3 图像处理 → P4 压缩 → P5 传输协议 → P6 系统与方法 → 附录"归属；Part 顺序=推荐阅读顺序=写作顺序。

## 5. 外部资源与链接核验规则（冻结）

- 每章 3–8 个外部资源；**中文资源（B 站/中文博客/知乎专栏/中文官方文档）优先**，英文权威源（JEDEC 摘要页、Micron/AMD/Intel/TI 官方文档、论文）作为深入补充；视频优先"能在一次 10–30 分钟内讲清一个概念"的整段课程或高赞教程，不选标题党/带货视频。
- 核验状态字段取值：
  - `在线核验通过 yyyy-mm-dd`（开发用联网工具实际请求过，且页面标题/作者与登记一致）；
  - `无法在线核验（原因）`：联网工具不可用时，**必须**给出精确检索词（可复现找到），准予交付；
  - `已失效→备选`：原链接失效时替换或降级为检索词。
- 不得虚构 URL/标题/作者/时长；拿不准的字段留"约"。视频/文档摘要只写推荐理由，不搬运内容。
- 工程维度验收：所有资源行有核验状态；`在线核验通过`行可被测试者抽样复现；`无法在线核验`行有可复现检索词。

## 6. 三维测试边界（文档任务缩放；冻结）

| 维度 | 本任务中的含义（验收对象） | 不适用项与理由 |
|---|---|---|
| functional（内容正确性与覆盖） | ① 通用原理/数字正确（抽样对核）；② 项目事实可溯源、与 input-index §3 基线一致；③ 覆盖冻结大纲要点、回答本章问题；④ 由浅入深层次成立；⑤ 决策卡可支撑"独立判断" | —（本维度为主） |
| engineering（结构与来源可核验） | ① 文件/命名/编码/模板必含节齐全；② 外部资源核验状态规则满足（§5）；③ 无禁止写法（§3）；④ 与大纲边界一致、交叉引用编号正确；⑤ manifest/SHA 与自检记录齐 | **时序/CDC/资源类检查=不适用**：纯 Markdown 文档，无 RTL/时钟/构建对象（引用 `.agents/skills/fpga-design-guide/SKILL.md`"纯文档配置只做静态复核"口径） |
| system（可用性与项目衔接） | ① 导航（README→章→节、前置/后续链接）可用；② 引用的项目路径真实存在；③ 至少一个用户示例问题（DDR1600/1333/800E）可从章节+决策索引得到判读；④ 术语/资源表可供后续汇总；⑤ 章节结论不与他章/决策冻结登记冲突 | **上板/长稳/G3–G5=不适用**：无硬件候选、无位流、无长稳对象；引用 report-contract"文档工作包可三维 PASS，G3 明确不适用" |

## 7. 所需工具与设备

- 仅需：文件读写、Markdown、联网检索工具（用于资源核验；不可用时按 §5 降级规则处理）。**不需要** TD、D 盘工程、板卡、仪器、下载/发布权限。
- 联网核验结果保存在本 run 目录（`link-check-KB<n>.json` 或等价记录），供测试抽样复现。

## 8. G 层与阈值（冻结）

- 适用：**G0**（规范/接口=本指南+大纲+模板；随包 manifest 冻结）、**G1**（静态/离线核验=内容抽样、链接核验、事实溯源、引用检查）。
- 不适用：**G2/G3/G4/G5**（无综合/STA、无位流/板测、无长稳、无端到端集成对象；理由=纯文档交付）。
- 通过阈值：三维均 PASS=本包"本章组知识书内容"完成（不等价任何硬件任务状态）；修复轮同 workflow 通用规则（round0 首测，最多三轮实际修复）。
