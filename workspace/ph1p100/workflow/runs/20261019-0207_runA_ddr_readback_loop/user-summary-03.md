# user-summary-03.md — 下一任务与进度（大白话）

**一句话：A、B 都做完后，下一步最该推的是“压缩”（任务板上的 T10，LZ77 + Bayer 前端 + RAW 回退，带独立软件解码和资源/吞吐证据）。整体进度：按赛题完整交付算大约 40%；只算现在这条 FPGA 侧主线（采集+读回+三算法）大约 80%。**

## 为什么是 T10（压缩）

- 任务板上 T10 本来就是 `ready`，而且明确写着“T09 收束后排队、等用户统一进度再恢复”；现在 T09 的生产集成都离线 PASS 了，正好轮到它。
- 它是后面 `T11` 集成（DDR→压缩→PCIe）的前置；不做它，集成没法往下走。
- 它也是目前剩余工作量最大的一块（对应 12 个小项：软件基线、Bayer 前处理、LZ77/位打包、块头/CRC/RAW 回退、双路吞吐、真实图集收益等）。
- 双路同步（T08）和发布材料（T13）要等它/或等双相机窗口；长稳和 RK 按你说的先放着。

## 这个任务具体是什么（一句话版）

做一个“单编码器”压缩闭环：Bayer 前端（可开关）+ 真实 LZ77 编码 + 块头/长度/CRC + 坏块时退回 RAW；同时写一个独立软件解码器，保证解回来 0 差异；再给出资源占用和持续吞吐证据（单A 1080p30 是 77.76 MB/s，双路 155.52 MB/s 只记录差距、不吹达成）。分 4 包：核心 RTL → 软件解码/比率 → 小顶 G2 → 冻结交接。
