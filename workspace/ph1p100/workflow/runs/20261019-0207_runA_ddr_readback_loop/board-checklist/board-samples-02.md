## 3. 机械观察的判读（word4 / word6）

### 3.1 word4 = DDR 源双缓冲地址轮换（非异常）

- RTL 证据（只读）：`upstream\…-wt0207\rtl\ep_side\ddr\ddr_frame_pusher.v` L137 注释“DDR 源双缓冲地址（与 cam_ddr_writer 的 BASE0/BASE1 一致）”，L140-143：
  `BASE0=32'h0010_0000`、`BASE1=32'h0090_0000`、`BASE0B=32'h0110_0000`、`BASE1B=32'h0190_0000`；L392-395 `par_base0/par_base1` 与 `par_valid = (ddr_base==par_base0)||(ddr_base==par_base1)`。
- C 的 `0x00100000` = BASE0、D 的 `0x00900000` = BASE1 —— **双缓冲轮换的两个合法源地址**；两者均非零且 128 B 对齐（低 7 位=0）。符合 Tier-2“word4 非零且 128 B 对齐”，**不是过渡态/故障**。
- 与 A/B（均 `00900000`）并存不矛盾：采样恰逢不同缓冲；`DDR_BASE_A` 锁存的是当帧发布时的基址。

### 3.2 word6 good 为 8 位每帧计数（模 256），四样本自洽

- 解码：`word6 = {good[31:24], bad[23:16], hdr_err[15:8], crc_err[7:0]}`；四样本 bad/hdr/crc 均为 0。
- 模 256 校验（good 增量 = word3 增量 mod 256）：

  - C(seq 15293, good 189)→D(seq 15764, good 148)：Δseq=471，189+471=660，660 mod 256=**148** ✓
  - 与基线（word3 +300、good 190→234=+44=300 mod 256）同口径。
- 结论：good 随发布帧递增（8 位回绕），**“word6 good 增长”成立**；坏计数恒 0。
