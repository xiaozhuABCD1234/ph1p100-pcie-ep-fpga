## 2. 下一任务定义：T10 压缩 RTL 与 RAW 回退

### 2.1 任务身份与目标

- **全局任务**：`T10`（state=ready；depends_on=T03、T04；不新增全局任务 ID）。
- **建议新 run 标签**：`T10.runD-*`（由新 run 原规划最终冻结）。
- **主要目标（1）**：交付**可综合、可独立软件解码验证**的单编码器压缩闭环——Bayer 前端 + 真实 LZ77 基线 + 块头/CRC/长度 + 块级 RAW 回退；满足单A 1080p30 持续输入预算，并为 `T11` 集成提供冻结接口。**不含 PCIe/RK 主机侧**。

### 2.2 可验收结果（4 项）

1. **RTL**：LZ77 匹配/字典、位打包/标准流收尾、Bayer 前端（A/B 开关）、块选择/块头/CRC/长度/RAW 回退、小顶 + TB；G1 全 PASS（含尾块/截断/反压/坏块/首帧/RAW 回退）。
2. **软件**：独立解码器（Python/C）+ 冻结向量 round-trip **0 mismatch**；负例（截断/坏 CRC/非规范尾部）拒收；A/B 压缩比与**最坏膨胀上界**（RAW 回退路径=原长+块头，不许用平均值代替）。
3. **工程**：小顶 G2（Routed、SWNS/STNS/HWNS≥0、资源在器件内）；持续服务率与最坏 RAW 回退带宽预算（单A 77.76 MB/s 目标；双路 155.52 MB/s **只标注差距**，不声称达成）。
4. **冻结**：candidate manifest/证据/回退 + `T11` 集成接口（格式、块头、长度/CRC 覆盖范围、枚举不自行分配）。

### 2.3 范围与非目标

- **建议写域**：优先 `upstream/ph1p100-pcie-ep-fpga` 新目录 `rtl/ep_side/codec/**`（新 worktree/分支，启动时冻结）；如坚持任务板旧路径 `fpga/csi2/src/codec/` 也须在启动时明确“唯一写树”。不分配压缩枚举（T03 合同）；不碰 T11 冻结输入；不改算法/相机/PCIe 源。
- **非目标**：PCIe/RK 实机、真实曝光同步、双路 60fps/4K、G4 长稳、发布材料（T13）。

### 2.4 前置条件（启动前必须冻结）

1. **格式/规则口径（需用户拍板或明确默认）**：自描述格式+自研解码 vs DEFLATE/GZIP 兼容优先（T04 注“规则替代接受口径未确认”；T10 注“不得自定义 token 声称 zlib 互通”）。建议：**先自描述+自研解码**，DEFLATE 兼容作为可选第二阶段（不阻塞进度）。
2. **真实图集（MP12）缺失**：先用冻结合成/参数化向量并明确标注；真实压缩比待图集/板测。
3. **T03 合同未签收**：压缩枚举/容器/RK 解码边界仍待 G0；T10 不自行分配枚举。
4. **写树与时钟**：上游 worktree + 目标时钟（建议 187.5 MHz，与 T09 同域）启动时冻结。
5. **T02 真实几何/相位**：影响真实图像合法性；不阻塞 RTL 核心，但真实图集验收需其证据。
