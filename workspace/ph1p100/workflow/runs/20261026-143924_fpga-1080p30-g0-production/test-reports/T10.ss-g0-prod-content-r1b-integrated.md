## 3. `dup` 语义与 `ss_pass=0`（写入正文，供 P2/P3/P4 引用）

- **源码（`a1_ddr_slot_store.v:280-284`，SHA `86d62646…`，与 r0/P4 逐字节相同，未改）**：

  ```verilog
  st_read_words <= st_read_words + 32'd1;
  if (rd_prev_v && (ddr_rdata === rd_prev))      // 281
      st_dup_words <= st_dup_words + 32'd1;      // 282
  rd_prev   <= ddr_rdata;                        // 283
  rd_prev_v <= 1'b1;                             // 284
  ```

- `ddr_rdata`/`rd_prev` 为 **`[255:0]`**；计数点在"读数据有效"分支内、与 `st_read_words` 同一拍、**一次读最多 +1**；比较的是**载荷数据**，无地址比较、无重发计数、无 CRC/ID 校验。
- **结论**：`st_dup_words` 是**内容统计量**——"相邻 256-bit 读字（等价于相邻 16 px packed RAW10，20 B 载荷）逐位相同"，即平坦区；**不是**重复读、不是重传、不是数据完整性错误，不影响 `S_ss/tail/sink_limited/G0` 与任何 CRC/自检。
- **测试者独立重建（r1 已做）**：对冻结 `raw_*.bin` 按 20 B 载荷切片统计相邻相同字数 → N 974×4=**3,896**、L 142×4=**568**，帧边界交叉项 **0**，与实测 `dup` **精确到个位**一致；旁证 `read=518,400`（无多余读）、`ar=r=728,086`、`raw_crc`/`header_crc`/`raw_bad`/`err`/`geom` 全干净。
- **`ss_pass=0` / `B11_FULL_RESULT pass=0` 的解释**：冻结 TB 的 `ss_pass` 表达式含 `st_dup==0`，自然内容下必然为 0；**这是 TB 便利旗标的后果，不是失败**（`B11_FULL_RESULT` 不代表验收判定；验收以显式 9 子句为准，guide §3 已同步说明）。
- **例外条款（r1b-ruling §2）**：若 `dup` 异常升高**且伴随** `read>518,400`、`ar≠r`、CRC/自检失败，则按数据完整性问题单独调查，不适用本豁免。本包不满足该例外（上述计数/CRC 均干净）。
