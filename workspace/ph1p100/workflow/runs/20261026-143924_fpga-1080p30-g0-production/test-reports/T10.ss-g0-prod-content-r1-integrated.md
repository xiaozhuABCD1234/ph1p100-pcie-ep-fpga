## 6. `dup` 语义裁决建议（A3 的关键）

**源码（`a1_ddr_slot_store.v:280-284`，未改）**：

```verilog
st_read_words <= st_read_words + 32'd1;
if (rd_prev_v && (ddr_rdata === rd_prev))
    st_dup_words <= st_dup_words + 32'd1;   // line 281-282
rd_prev   <= ddr_rdata;
rd_prev_v <= 1'b1;
```

- `ddr_rdata`/`rd_prev` 均为 **`[255:0]`（256-bit）**，`rd_data` 同为 256-bit。
- 计数点在"读数据有效"分支内，与 `st_read_words` **同一拍、一次读只可能 +1**；不是地址比较、不是重发计数、无 CRC/ID 校验。

**测试者独立重建（决定性）**：把冻结 `raw_*.bin` 按每读字 20 B 载荷（= 4 个 5 B 组 = 16 px packed RAW10；129,600 字/帧 × 20 B = 2,592,000 B）切片，统计"相邻逐位相同的载荷字"：

| 类 | 单帧相邻相同字数 | ×4 帧 | 预测 dup | 实测 dup | 帧边界匹配 |
|---|---|---|---|---|---|
| N | 974 | 3,896 | **3,896** | **3,896** | 0 |
| L | 142 | 568 | **568** | **568** | 0 |

- 两类**精确到个位**吻合，且帧边界交叉项为 0 → `dup` 完全由"内容里相邻读字载荷相同"解释，**无任何残余可归因于重复读/重传/地址错乱**。
- 旁证：`st_read_words`/`read=518,400` 与预期字数完全一致（无多余读）；`raw_crc` 与内容 bin crc32 相等、`raw_bad=0`、`header_crc` 自洽、`err/geom/wd=0`、`ar=r=728,086`；合成 C1/C2 内容 `dup=0`（P4 证据），自然图像的平坦区（N 天空/水面 0.7516%、L 夜空 0.1096%）必然 `dup>0`。

**结论与建议（测试者不自行改门槛）**：

1. `st_dup_words` 是**内容统计量**（相邻 256-bit 读字逐位相同，载荷等价于相邻 16 px 相同），**不是**重复读/重传/数据完整性错误；它不影响 `S_ss/tail/sink_limited/G0`，也不影响任何 CRC/自检。
2. 因此**不建议**把 `dup=0` 留作 **A3 数据完整性门槛**：该子句只在"合成梯度/随机"内容上恒成立，对真实自然内容必然失败，属"门槛假设与内容不兼容"（与 r0 的 `WD_LIMIT` 同类），**不是 DUT 缺陷**。
3. 建议规划裁决（三选一，均不改 DUT/内容/G0 门槛）：
   - **建议 A**：A3 有效性改为 `raw_drop=cmp_drop=geom=err=wd=0`，`dup` 仅作记录字段（同时同步 dev-plan P2 B3 与 guide §3 的 `dup=0` 措辞）；若采纳，本任务 A3 的其余 8 项已全部通过，**无需重跑**即可转 PASS（证据绑定 manifest-r1）。
   - **B**：保留 `dup=0`，则自然内容 A3 永远不成立，本包只能以 `partial` + `G0_not_proven` 收口，且 P2 的 `dup=0` 条款必须同批改写，否则 P2 也会被同一假设卡住。
   - **C**：把 `dup` 从冻结 TB 的 `ss_pass` 表达式中移除（round2 新 TB + 白名单 diff，需另计 harness 预算），`dup` 仍在 stats 中报告。
4. 在裁决前，测试者**不豁免**该子句，故 A3 判 **FAIL（仅 dup 条款待裁决）**；也不把 `dup` 当数据完整性失败。

## 10. 边界、未测项与下一步

**边界（不得外推）**：内容仍是**自然场景图像派生 Bayer**（`proxy_not_natural_raw` + `not_sensor_raw` + `proxy_not_worst` + `display_referred`），**不是**真实传感器 RAW，不能证明 IMX415 噪声/光学/CFA、最坏内容；pacing 仍是 TB `wait_slot_free`（非生产自由跑）；sink 仍是冻结 93.75 MB/s TB 代理（非生产 sink）；DDR 为行为级模型；单路/单核/187.5 MHz；**双路、板级、PCIe、RK/NPU、192.642 MHz、资源/时序均未测**。

**未测**：L 的全尺寸逐字节重跑（本轮只要求 1 次，N 优先）；生产 free-run pacing 与丢帧；生产 sink ≥103.79 MB/s；真实 DDR/PAXI sustained；时域变化的 4 帧（本包为同帧重复）。
