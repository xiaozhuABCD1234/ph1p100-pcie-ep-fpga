# 队友两个参考仓库：有价值点清单（只读汇总）

> 按您的要求，本次只"指出来"，**没有**动您现有代码/工程，也没有运行队友仓库里的任何脚本。两仓库已只读评估（网页匿名访问 404，非公开；评估记录含 HEAD commit 与文件 SHA，见 `workflow/runs/20261016_185639_td_cli_iptool/input-index.md` §6）。本清单不改变正在进行的实验和任何任务状态。

**两仓库是什么**：同一块米联客 MLK-F9P 板（PH1P100SBG484）上的姊妹工程——FPGA 端是 PCIe Gen2×2 EP + IMX415 相机 + DDR3 帧推送（TD 6.2.3 / Linux 版），主机端是 RK3588 驱动 + Rust 用户态工具。与我们同板、同族相机与 DDR，但数据面路线不同。

## 一、对当前卡点直接有价值（DDR IP 生成 / TD CLI）

1. **同族根因经验（最有价值）**：他们记录的 DDR IP 生成失败根因 = IP 实例的 ADC 引脚约束（`PH1P_IO_ASSIGN`）为空 → 生成脚本打开空路径报错 → 生成失败。这与我们 14 次受控实验的 `#IP Generate Failed!` 属同一族问题；而且他们**用的就是我们同一份 `ap115v2_ddr3_x32.adc`**，其 DRC 前提与引脚规则细节可直接对照我们的现场。
2. **成功配方的路线价值（注意版本）**：他们的成功配方是 TD 6.2.3 的 Tcl IP flow 命令（`create_ip / load_project_ips / set_property / generate_target`…）。我们本机是 TD 6.2.2，规划者已实测**这些命令未注册**，配方不能照搬；但其经验确认了两条现实路径——升级 TD 或走 GUI，且他们最终交付也是走 GUI。
3. **可直接引用的坑清单**：`set_property` 参数顺序写反会静默失败；`open_project` 后必须 `load_project_ips`；`.al` 会被工具静默改写；depot 自带 example_adc 是别的板子（引脚全错）；`ipgen_gui_*` 日志模式与我们的 09 例程一致。
4. **GUI 点击清单**：与我们已准备好的 190248 人工包高度一致 → 若走"用户在场 GUI 生成"，可作独立佐证。

## 三、不能照搬的边界

- **TD 版本差异**：他们 6.2.3 / IP 生成器 2026.08，我们 6.2.2 / 2026.03——Tcl IP flow 命令我们机器上没有（已实测）。
- **频点与配置不同**：他们的 DDR3 IP 是 800 Mbps 口径，我们现役 1600、候选 1333——其参数/ADC 不能直接拿来用。
- **数据面路线不同**：他们是 PIO/寄存器/帧推，我们是 C2H 固定块；只可参考，不能当同一条链路。
- **性质**：外部材料，未执行其脚本、未并入我们工程；引用以 commit/SHA 记账。
