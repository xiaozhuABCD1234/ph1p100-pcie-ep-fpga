## 4. PATH 副作用影响评估（独立判断）

**现状（实测）**：用户 PATH 顺序 `…;[11] D:\downlaod\bin\;[12] D:\anlogic\TD_Release_2026.2\bin\`——新旧两 bin 并存，**新的追加在旧的后**；机器 PATH 无 TD bin。裸名解析（如 `td_commands_prompt`）在新开 shell 中仍会优先命中 **6.2.2**。

**对本项目的影响评估**：
1. 项目工具纪律：`tools/td/*.py` 关键脚本**全部使用绝对路径常量**（如 `verify_cli_e2e.py` 的 `TD_EXE=Path('D:/downlaod/…')`；`run_ddr1333_ipgen.py` `IPTOOL/TD_CLI/TD_ROOT` 亦然）——**不受 PATH 顺序影响**；本批实测副本亦为绝对路径。
2. 风险点：①文档示例（`tools/td/README.md` L85 的 `td_commands_prompt.exe ./…` 裸名示例）若被照抄到别的 PATH 环境可能解析到非预期版本；②任何未来若预置/重排 PATH，解析目标会静默翻转（两版共存期的固有脆弱性）；③`.al` 双击默认已指向 2026.2 GUI（行为变化，已披露）。
3. **该影响已被注明**：dev-notes（261016 2242 条目）与 `upgrade-review.md` §2.3（"并行安装后所有脚本一律绝对路径，防止裸名解析到非预期版本"）均有书面纪律；本测试者独立判断与之一致。
4. **结论**：影响低、无即时治理必要；**建议列入 T01.tool-C 文档增补**：在 `docs/TD命令行使用说明.md` 增加"双版本共存"小节（绝对路径纪律 + 两 bin 顺序 + `.al` 关联变化 + 裸名示例改绝对路径写法）。可选后续治理项（非本批必需）：全仓检索文档中的裸名示例统一为绝对路径。
