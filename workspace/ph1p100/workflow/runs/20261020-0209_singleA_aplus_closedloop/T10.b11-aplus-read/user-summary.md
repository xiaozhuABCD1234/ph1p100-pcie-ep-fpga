# T10.b11-aplus-read — 用户摘要（规划冻结）

- 结论：b10 r1 的板级卡点**不是 A+ 核死锁**。状态包显示核已开帧并愿意收数（`a1_in_ready=1`），
  是 feeder 等不到 raw 读数据（`fstate=F_WAIT`，`raw_rd_valid=0`）；reader 停在 `R_RW`，已发 1177 个 AR 只回 1176 个 R，
  **确定性丢 1 拍 DDR 读响应**（b9、b10 都恰好停在 1176 字）。
- 本轮任务：`T10.b11-aplus-read`（新包，父 T10 仍 blocked）。先在**真实 A+ core 全尺寸仿真**里复现并定位，
  只改被证明的那一点，并加“有界看门狗”防止以后再永久挂死；同时把状态包升级到 **v4**（225 B，55 个字段，
  增加桥/PAXI/reader 握手与 A+ 核 `S_*` 状态，整包单边沿快照）。
- 验收：P1 三黄金逐字节不变；1920×1080 两帧读满 129,600 字并导出 2 帧；重建 Routed 0 违例、WNS≥+0.05；
  **先下载后开 COM8**，采 150 s，`enc_frames/exported` 增量>0，至少 1 帧 44 B 头 + 四 CRC + zlib 通过。
- 预算：开发 150 min/70 calls；TD 3 会话、综合≤3、布线≤2、bitgen 1、CWC 1、下载 2（只能同一 bit）；不写 Flash。
- 若 50 min 内无法解释 1176 字停点：本轮只做 v4 诊断构建（不加猜测性修复），不宣称目标达成，也不申请第二个 bitstream。
- 不需要用户输入；连续烧录授权按用户最新原话执行（SRAM）。
