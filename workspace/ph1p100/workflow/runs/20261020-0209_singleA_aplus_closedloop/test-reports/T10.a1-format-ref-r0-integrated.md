### 3.1 非阻断性工程发现

**F1（中等，P2/P3 需补）— 严格解析器的块级几何约束不完整。**
`a1_inflate_strict.py` 检查 stored `LEN<=4800`，但不检查 fixed block 解码后的长度上限，也不拒绝“立即 EOB”的空 fixed block；`expected_len` 只约束整帧总长。格式 §3/§4 冻结了“1 block = 1 个 2 行对、≤4800 B、空块非法”，因此严格解析器对这些规则并不完全严格。P1 的所有向量块长已由本测试者独立核验正确，冻结负例也未包含此类用例，故不作为 P1 门槛失败；但 P2/P3 用该解析器验收 DUT 码流时，必须另加 block 边界/长度断言，否则一个“单块 9600 B、总长正确”的 DUT 流可能漏过。

**F2（低/中，P4 容量需补）— 2,594,706 B 是 all-stored 实测上界，不是已证明的混合块全局上界。**
该值与 540 个 stored 块（每块 5 B 头开销 + 2 B zlib 头 + 4 B Adler）逐字节一致，已由随机 1080p 向量证实。但若流中混合 fixed 与 stored，fixed 块结束在非字节边界时，下一 stored 块需要 0–7 bit 对齐补位；“540×5 B”推导未覆盖该补位。P4 做缓冲/最坏膨胀容量时不应把它当作已证明的硬上界，应增加专门的最坏构造或留出余量。该风险不影响 P1 正例/负例门槛。
