# T10.b9-rawstore 用户摘要

**本轮判读（有板级实测证据）**：b8 那次 90/150 s 采集里，`crop_roi_frames=3300`、`crop_groups=1,710,720,000 = 3300 × 518,400`、`geom_err=0`、`short=0` —— **相机→MIPI→裁切完全通了，每帧 518,400 组一组不差**。但 `raw_pub` 的 OR 掩码恒为 `0x00000002`：**只在采集最早期发布过 2 帧，之后 88 秒一动不动**，同时 `raw_drop=0、errors=0、enc_frames=0、exported=0、read_words=0`。

**这组数字本身就指明了方向**：能发布 2 帧，说明写 DDR 的通道**确实工作过**（每次发布要 129,600 次写、2,592,000 B 精确匹配才算数）；之后既不发布也不丢弃也不报错，说明**两个 slot 被占满后新帧全在入口被拒**，卡点在「发布之后」——读侧，而不是写侧。

**格式核对结论（用户问题 1）**：全部整除、自洽，不是长度/打包不匹配。
- 480 beat/行（1920/4）× 1080 = **518,400 组/帧**；
- 4 组/256-bit 字 → **129,600 字/帧**；帧字节 1920×1080×10/8 = **2,592,000 B**，÷20 B/字 = **129,600 字**，正好整除；
- slot 容量 2^18=262,144 字 > 129,600，slot1 基址与压缩区不重叠。

**静态核对抓到 4 个明确缺陷（本轮直接修，用户问题 3 的"明确 bug"成立）**：
- **F1 abort 过不了 CDC**：crop 的 `out_abort` 只拉一拍、同拍 `out_valid=0`，而 CDC FIFO 只在 valid 拍写 → A1 侧永远收不到 abort → 一旦某帧被中止，store 永久停在「写」状态，再也不接新帧。
- **F2 没空 slot 时整链静默冻结**：入口拒绝时把 FIFO 反压按死 0，而 FIFO 写侧满即静默丢 → **整帧数据被悄悄丢掉，`raw_drop` 却仍是 0**。也就是说 b8 的"raw_drop=0"不能当"没丢帧"的证据用。
- **F3 P2 DDR 桥读请求可丢可重发**：读请求的弹出没和「请求真的发出去了」绑定，DDR 未就绪时还会重复发 → 读回的数据错位并最终永久卡死。
- **F4 raw store 的 `ddr_ready` 被硬接 1**：完全看不见 DDR 是否就绪，违反 store 自己的契约。

**本轮交付**：
1. 状态包升 **v3**（5 B 头 + 43×32b = 177 B，前 23 字段与 v2 一致），新增 raw 写侧/读侧计数：`wr_begin_ok/deny`、`wr_beats/wr_words`、`wr_ptr`、`wr_state`、`rd_state`（含 `a1_busy/a1_out_valid/rd_open_ready/begin_ready/fstate` 全部闸门位）、两个 slot 状态与长度、`ar_valid/ar_hs/rv_cnt/rd_open_ok/rd_close`、`abort_cnt`、拒绝原因。**整包同一拍快照**，避免多位跨域撕裂。
2. 修 F1–F4；数据格式/帧头/CRC/DDR 布局/SDC/引脚一律不动。
3. P2 重建：Routed 0 违例、WNS ≥ +0.05、1 bitgen + 1 CWC。
4. **1 次 SRAM 下载**（先开 COM8 再下载）+ 90 s 采集。

**本轮判定门槛**：
1. **诊断门（必须过）**：v3 能四选一唯一定位——A 读打开了但 DDR 不回数 / B 连 AR 都发不出 / C 读根本没打开（并指出哪个闸门）/ D 写侧没起来，并给出"卡在哪一拍、为什么没发布"的一句话结论。
2. **修复门**：90 s 内 `raw_pub>0` 且 `enc_frames>0` 且 `exported>0` → 再按 44 B 头 + CRC + zlib 解码出 1920×1080 图。
3. 只到 `raw_pub>0、enc_frames>0、exported=0` 记 ⚠ 未通过并保留证据（115200 波特下整帧导出可能超 90 s），**不二次下载**。

**风险（如实）**：F3 的修法需要仿真证明"每字恰一次 AR、无重复数据"，否则宁可只交诊断门也不冒险上板；v3 计数器会让资源略增（约 3~4k FF），门槛设了相对 b8 ≤5% 的护栏。

**需要用户输入**：无（本轮 1 次下载窗口已授权）。**下一步**：派 fpga-dev 执行 `T10.b9-rawstore`，做完交一个综合测试者按同一冻结 manifest 独立复核。
