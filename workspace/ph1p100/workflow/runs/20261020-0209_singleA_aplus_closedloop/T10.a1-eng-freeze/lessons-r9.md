# lessons — T10.a1-eng-freeze r9

1. **中断后先比对输入哈希再信旧结果**：r9/p2、r9/p3 早于 RTL mtime 且输入哈希不同，旧 FAIL 结果早已失效；不核对就会把工具/中间态问题当成真实回归。
2. **同一存储的两套位域打包必须同源**：htab 写入用旧打包 `{tag,pos,w0..w2}`、读/旁路用 `{tag,pos+3,pos,w0..w2}`，仿真表现为“偶发命中缺失/距离异常”；固定为单一 `htab_we_data` 后回归全过。
3. **加寄存器地址比加宽组合路径更划算**：`bm_a[pos+3]` 直接把 pos 的 1224 扇出 + 加法器塞进 hit 捕获路径（-0.789 ns）；改为 `bm_a[raddr]` 并证明 `raddr==pos+3` 不变量后回到 -0.434 ns。
4. **pos+3 存表确实去掉了 htab 读后加法，但剩余瓶颈是两级异步小存储读（bm_a/bm_b）+ 命中比较**：187.5 MHz 下这一结构在此器件/布线模型里仍约 5.7 ns，单靠本路径无法闭合；继续局部补丁收益已耗尽。
5. **TD 二次运行需换干净工程目录**：同一目录 `create_project -force` 后再 import 会报 `PRJ-8642 … .al does not exist`；新目录（r9/td2）即恢复，且该失败不产生综合结果、不计综合尝试。
6. **验证等价性的最省成本方式**：直接比对 `p2/p3 result.json` 的 sha256 与 r8 一致，比逐项字段核对更快且更严格。
