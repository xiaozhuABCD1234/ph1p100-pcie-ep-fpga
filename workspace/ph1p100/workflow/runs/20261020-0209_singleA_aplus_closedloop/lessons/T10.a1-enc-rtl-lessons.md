# T10.a1-enc-rtl lessons

## 结果
P2 模块级 RTL 编码器在 13 个正向用例、80 个负例、反压/abort/reset 下全部 PASS；zlib 与自研严格解析器双解 0 mismatch，P1 帧 Bayer 逆变换 raw 0 mismatch。吞吐实测：压缩友好 87.27 MB/s、随机 178.35 MB/s（187.5 MHz，模块级，输出常 ready）。达 77.76 门槛，未达 97.2 余量目标。

## 有效的做法
1. **以“位流长度”为唯一事实来源**：candidate bit count、stored cost、回放 bit 数三者独立计数，任何一处偏差都会在块边界暴露。先写单块最小用例（8×4）比直接跑大帧更快定位。
2. **双解码必须走不同实现**：zlib 抓流合法性/Adler，自研严格解析器给 reason code 与 token 统计；再用 ref 逆变换做样本级比对。三者缺一都会漏掉“能解但样本错”的问题。
3. **负例要做在 DUT 输出上**：截断、坏 Adler、坏 NLEN、非法 BTYPE、尾随字节；同时要求 zlib 也失败，避免“自研解析器自证”。
4. **stored 路径单独计时**：两状态/字节会直接吃掉一半吞吐；把 read+push 合并到同一状态后随机吞吐翻倍。
5. **提前回退用“已用位数 + 剩余字节×8”**：对不可压缩块几十字节内即可判定，避免先做完整候选；对可压缩块只有在确实要输给 stored 时才触发。
6. **中文路径**：ModelSim 必须 `subst`；PowerShell 脚本不要硬编码中文默认路径，用 `$PSScriptRoot` 推导，否则脚本按 ANSI 读取会生成乱码目录。
7. **PowerShell 调外部工具**：`Start-Process` 的 `-do "run -all; quit -f"` 必须作为**单个含引号参数**传入，否则 `-f` 被当成 vsim 选项；函数返回 `WaitForExit()` 的 bool 会污染退出码，需 `$null=` 或赋值。

## 踩过的坑（根因）
- **同步读延迟**：`addr` 在时钟沿更新，`data` 要到下一拍才有效；PRE/REPOS 直接把 `cq` 当同拍数据，导致 match 后首字节错。P2 改为组合读；P4 若改回同步读，必须重排预取。
- **函数分支下溢**：`len_extra_val` 的 `l<=18` 分支把 len=3 算成 24，高位污染后续码字。修复后仍在 push 入口加位掩码，防止任何函数高位泄漏。
- **尾部残余位**：`cacc` 里的不足 8 bit 没有写进候选 RAM，回放读到未初始化字，输出 `xx`。EODONE 必须同时处理“整字节未配对”和“残余 bit”两种情况。
- **地址位宽**：4800 B 块需要 13 bit offset；只取低 12 bit 会让 4096..4799 覆盖 0..703，表现为“小帧对、大帧 Adler 错”。
- **负例位操作**：把 BTYPE 从 01 改成 10 要同时清 bit1、置 bit2，只置 bit2 得到的是保留值 11。

## 交接/后续
- P3 直接用 `a1_deflate_core` 的块接口；`frame_commit` 必须由 top 结合 `done`、`abort`、溢出与几何合法性生成，不能只看 `out_last`。
- P4 重点：块缓冲组合读改同步读、ERAM 映射、资源/时序、整帧持续服务率复测；87.27 MB/s 距 97.2 还有约 11% 缺口，需并行化或更宽输出，不能靠理论值。
- 本包所有输入为 synthetic；真实 RAW、物理 Bayer 相位、板级/PCIe 仍未验证。
