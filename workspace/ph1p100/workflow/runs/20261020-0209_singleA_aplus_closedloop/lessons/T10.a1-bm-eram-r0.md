# lessons — T10.a1-bm-eram r0（bm 同步 ERAM 读；htab 尝试与 fabric-shadow 变体）

补充上一版，只记本轮新增的可复用结论。

## 1. ERAM 的 clk2q 是新的时序主角（≈1.5 ns，fabric FF 只有 ≈0.4 ns）

- bm 从 LUT-DRAM 换 ERAM 后 slice 15,108→**5,259**、ERAM 22，DRAM 长线彻底消失，但 worst path 变成
  `bm_a ERAM clk2q → bm_a_rd → hash3 → htab_rd_addr → htab_v LUT-RAM 读 → htab_rvalid`（6.363 ns，-1.094）。
- 结论：**不要用 ERAM 的输出寄存器直接发起下一级存储的地址生成**。要么在 ERAM 输出后插一级 fabric 寄存器（预取再提前一拍 + shadow），要么让被访问的下一级存储也变成 ERAM（把 clk2q 换成"地址→寄存器"的短路径）。

## 2. 把 1024×66 的 LUT-RAM 变成 ERAM：只移写口不够

- 把 `htab[...] <= ...` 从主（复位控制）进程移到独立无复位 always 后，**ERAM 仍是 22、时序一字不变** → 说明挡住推断的是读侧结构：`if (htab_pref) rdata <= mem[addr]` 的使能 + 同址写穿透 mux（`if (htab_we && rd_addr==ins_addr) rdata <= ins_data`）+ 66 bit 宽度。
- 想要 ERAM 化必须同时：读地址无条件打拍、写穿透改成"对 rdata 的下一拍选择"、宽度拆成 2 的幂、以及给 `htab_v` 找替代（它的复位清零与 ERAM 冲突）。

## 3. "预取再提前一拍 + fabric shadow" 的功能风险点

- 主链（S_SCAN）很容易对齐：`x1_r <= xf_r; xf_r <= bm_a_rd; praddr = raddr+4`（S_SCAN）、`+3`（pre/REPOS），窗口不变量变成 `w0..w2=bm[p..p+2]`、`x1=bm[p+3]`、`xf=bm[p+4]`。
- **坑一（会丢符号）**：pre 阶段的 htab 读地址若用到 `praddr` 的陈旧值（S_BHDR 那一拍），地址会变 X → `htab_v[X]` = X → `hent_v` = X → `hit2` = X → `cp_en` = X → **该块第一个 literal 被吞掉**（解码少 1 字节、码流合法但内容错）。修法：在 S_WAIT 就把 `praddr` 种好，不要只在 S_BHDR 种。
- **坑二（等价性破坏）**：即使所有读地址"看起来"都对，`pre/REPOS` 阶段有一次读（rp2/pre2）的字节组合与基准不同时，命中会变 → 插入序列级联变化 → 同一输入编出**不同但合法**的码流（本包 5/13 例中招，例如 len3_dist4 由 9,909 变 21,623 cycles）。**这类差异用 verify PASS 是查不出来的，必须逐例比 stream_sha256 + run_cycles。**

## 4. 验证口径

- 只跑 verify（zlib/strict/Bayer）只能证明"功能对"，证明不了"与基准逐位相同"。冻结条件里写了 SHA/cycles 等价时，必须逐例比较（P2: `stream_sha256`+`stats.run_cycles`；P3: `p1.sha256_stream`+`cycles`）。
- 每次改 RTL 先跑最小的失败例（`p1_p_8x4_grad_prep1_pred0`，20 字节×2 块）并打印 `w0/w1/w2/x1/xf` 与 `bm[pos..pos+4]`，比跑全量 P2 快一个数量级。

## 5. TD 脚本坑

- `regexp {#dram\s+([0-9]+)} $atxt -> dr` 在本设计的 area 报告里不匹配 → `puts $dr` 直接报 `can't read "dr"`，tcl 在 gate 判定前中断（综合已完成、报告已复制，但没有 gate 结论也没有布线）。报告解析的每个 regexp 变量都要先初始化。
- `td_env.ps1` 不带 `-Force` 只会报错退出，**不会阻止后面的 `td_commands_prompt` 用旧 T: 启动**（上一轮因此把 area-map 的 `phy_1` 清空）。启动 TD 的正确姿势：`td_env.ps1 -Force -TdDir <本包 td>`，然后 `Test-Path T:\01_*.tcl` 确认拿到的是本包脚本。
