# T10.b1-a1-uart-integ r2 — lessons

1. **先证伪"参考错"，再怀疑 DUT**：8×2 微型几何（1 个 DDR 字、ROI 原点非零）一次跑通即可同时验证 (a) 参考 ROI 约定、(b) crop 的 eff_line/eff_grp、(c) pack/unpack 约定。r1 的 2,077,900 B 差异与参考无关，微型几何 30 秒就排除了整类假设。
2. **"全部字节 = 参考平移 N 字节"是极强的定位信号**：对全帧统计 `raw[i]==exp[i-k]` 的匹配数，一次性得到"恰好多/少一个 K 字节单元"。本次 k=20 = 一个 4 组 256-bit 字，直接把问题锁定到字级而非组/样本级。
3. **用 DDR 模型内存取证区分写侧/读侧**：`examine /tb/.../u_ddr/mem(0..3)` 是最快判据——mem 内容正确即写侧无罪，缺陷必在回读/馈送。比再加计数器更快（无需改 RTL）。
4. **首字重复在单字帧不可见**：8×2（4 组 = 1 字）能过、32 字帧失败。凡是"只在小几何通过"的模块，必须至少跑一个跨多个存储字/块的用例，否则首尾字边界错误会被掩盖。
5. **写域纪律**：r2 只授权 `a1_uart_export.v`（header 时序）与诊断，根因落在 store/arbiter/feeder 时不得顺手改，应带证据交规划授权；否则"修好了"也无法审计。
6. **header_crc 的寄存同拍读**：`crc_fin <= ~crc32b(...)` 与 `tx_byte_r <= hw10(=crc_fin)` 同拍时读到旧值；应在最后一字节（idx==39）预算下一页要用的值。同类"同拍寄存后立即消费"的地方都要检查。
7. **仿真预算分配**：整帧 1080p 约 3.5 min/次；先用 1 字/32 字小几何定位（秒级），最后才跑整帧，可省 2-3 次整帧。
