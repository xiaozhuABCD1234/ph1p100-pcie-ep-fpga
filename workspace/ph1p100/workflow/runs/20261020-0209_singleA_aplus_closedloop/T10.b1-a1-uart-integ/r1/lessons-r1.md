# T10.b1-a1-uart-integ r1 — lessons

1. **位宽截断是静默错误**：`keep[0]+keep[1]+keep[2]+keep[3]`（全 1-bit）在 Verilog 里是 1-bit 和，keep=0xF → 0。任何 popcount/求和先拓宽到能容纳最大和（4 项 → 3 bit）。现象是"槽长度=1 B"和导出停在中途。
2. **计数寄存器必须按最大值定宽**：`out_cnt` 16 bit 只能装 65,535，而 1920×1080 ROI 有 518,400 个组 → `out_last` 永不触发、整帧被判短（`cap=0, geom=1`）。小几何（128）能过，整帧必挂 —— **几何参数变化时必须重算所有计数位宽**。
3. **多字打包按 lane 定位，不要靠移位链自然顺序**：`{pack_r, new}` 把最新字放在最低位，整组读出就是倒序；PC 侧第一症状是"payload 不是 zlib 流"（首字节 0xd3 而不是 0x78）。正确写法 `pack_r | (word << (k*W))`，k 为当前 lane 序号。
4. **寄存脉冲 + 自增 ID 有 1 拍错位**：`wr_begin` 寄存输出、`id` 同拍自增，槽锁存的是新 id，而描述符用 `id-1` → 恒差 1。要么 begin 组合输出，要么两边都用自增后的值。
5. **复位会清 DUT 计数器，TB 的绝对等待会挂死**：`wait_export(2)` 在帧中复位后永远等不到。等待应写相对目标 `target = st_exp + n`，并在复位后重新取基准。用 ModelSim `when` 事件表（FRAME_START/COMMIT/ABORT/EXP1）可 1 次运行看清相位与计数时序。
6. **`when` 条件的立即数要带宽度**：`{sig == 2}` 会被当二进制解析报 `Invalid binary digit`；写 `sig >= 32'd2`。`-do` 中路径用 `/`。
7. **自洽 ≠ 正确**：整帧 stream/xform/raw 三 CRC 全对只证明"导出=编码=存储"链路自洽；逐样本参考比对才能证明 ROI/图案/相位正确。两者必须分开报告，不能用前者代替后者。
8. **先修已定位再重跑**：r1 每次整帧仿真约 3.5 min，3 次重跑占了一半预算；离线先算清位宽/lane 顺序可避免。
