# T10.b1-a1-uart-integ r4 — lessons

1. **复位会清空所有故障计数**：`crop_geom/crop_short`、store 的 `st_dropped` 等都在 `!rst_n` 分支清零。因此"帧中复位 + 故障计数"在同一轮里不可能同时取证（本轮实测：驱动 12 帧、`roi_frames=9` 证明 3 帧未发布，但 `crop_geom=0`）。正确做法是**两轮**：无复位轮取计数、复位轮取"不发布半帧 + 恢复发布"。
2. **用"帧数差"间接证明中止**：当计数器被清空时，`roi_frames`（或 `cap`）与驱动帧数之差仍能证明"有帧未完成"，可作为二次证据；但不得把它当作 `geom/raw_drop` 计数。
3. **相位常数必须由帧长推导**：`FRAME_CYC=(ROI_Y+H)*(CG+LINE_GAP)+FRAME_GAP`；复位点写成 `FRAME_CYC-60` 落在帧内且不越界。固定 352/3000 会把复位放到帧外或帧前。
4. **复位点位置决定是否死锁**：`FRAME_CYC-60`（帧尾前）可跑完，`FRAME_CYC/2`（写入中途）整轮超时。上板前必须单独确认"写入途中复位"的恢复路径（P3 会真实遇到）。
5. **TB 逐行 patch 要防呆**：一次"no-op guard"把目标行替换成字符 `X`，导致 3 个 vlog 语法错误且后续运行静默使用了旧二进制（stats 看起来像新结果）。改完必须 `vlog` 检查错误数，并在运行前删除旧 `.stats` 以免误读。
6. **shell 不可用即停止**：收尾两次 `Permission denied: shell` 后按有界规则停止，不用 write 工具伪造运行结果；结果文件明确写"未运行"。
7. **测试-only 轮的价值**：即使未能补测，本轮也把"复位清计数"这一结构事实固化下来，避免后续再把两件事塞进同一轮。
