## 3. word6 good 非单调的归因（不掩盖、不武断）

- bad/hdr_err/crc_err 三位全 0 → CSI 数据没有解析错误；相机流在走（word3 帧号前进、word4 缓冲切换）。
- good 从 242 掉到 11 的最可能解释：该字段是**帧内/滚动的"已收到好行数"**（随采样时刻落在帧内相位不同而波动），而不是累积计数；两样本间隔（<10 s 与 >10 s 不确定）与帧号差 281 帧也支持"两次采样落在不同相位"。
- 备选解释：字段位序假设（good[31:24]）为冻结判据所用；本轮不改判据。若规划要确证，可让用户在下一次触发时**连续快照两三次**或读第二组 CSI 字，属后续可选动作。
- 该现象**不影响身份/长度/CTRL/写入流水**这些硬结论。

## 4. G3 适用范围（诚实边界）

- 本轮 G3 **仅覆盖**：FPGA 侧内部读通道（ChipWatcher 直读）成立、身份/版本/长度/CTRL 正确、DDR 写者流水在动、CSI 路径有活动且无解析错误计数。
