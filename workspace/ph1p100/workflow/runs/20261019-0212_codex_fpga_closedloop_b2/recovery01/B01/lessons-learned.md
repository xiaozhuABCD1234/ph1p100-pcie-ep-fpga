# recovery01 lessons

1. The original integrated TB compilation issue was declaration ordering. Split new wire declarations from the memory process; place wires before the writer instance and processes after all referenced source declarations. The third cumulative invocation compiled and completed the real full1080p writer/memory/checker test.
2. Cancelling a checker operation must not withdraw an already offered AXI ARVALID. An owned request skid keeps ARVALID/address/len stable until ARREADY or DDR reset; a separately counted accepted burst drains before slot release. Control TB covers abort with AR stalled, timeout with R stalled, RID/RLAST/AXI/CRC/length errors, two queued slots, session isolation and fail-closed missing-response lock.
3. done and words_read are sticky completion outputs. A test must first synchronize to a new busy operation and use the DUT's internal progress counter only for deliberate mid-transfer fault timing; otherwise an old completion can trigger the next test's fault too early or too late.
4. Monitor ready/valid transfers at posedge before nonblocking updates; drive ready on negedge. Checking after an accepted beat has advanced the FIFO can invent a hold/data failure. The corrected real ROI test checks three variable-image frames against an independent Bayer/gray/Gaussian/previous-frame HE oracle, and the ROI-offset negative control is rejected.
5. The legacy PCIe simulation stub lacked the INTX port triplet needed by a real top elaboration. Added direction-only ports are simulation-only; the production implementation continues to use the actual protected vendor IP.
6. Stress geometry must exceed algorithm buffering: W64/H16/FIFO16 with all sinks stalled caused a real overflow, rejected the algorithm frame, retained RAW correctness, then recovered. Two held RAW slots were not overwritten; the subsequent internal abort was rejected and a good frame recovered.
7. Preserve old manifests/reports and snapshot all prechange files by SHA before source changes. Recovery outputs stay under recovery01/B01. T08's26 frozen inputs are checked independently and not added to B01's active dependency set.

8. Freeze required recovery and completed-result probes before the first physical attempt; derive recovery from the exact post-rejection publication and full checker completion, not an old queued good frame.
9. When registering a production algorithm boundary, carry every data lane and SOF/EOL/EOF/abort with one enable. Retest numerics and handshake coverage; a latency change can make a short directed stall miss all outputs, so strengthen the stimulus rather than remove the hold assertion.
10. Whole-flow TD runtime includes synthesis and route/bit postprocessing. Preserve checkpoints and actual timeout evidence; a timed-out build is not G2 PASS. Verify owned children and temporary mappings after termination.

11. A shared-enable data register can cut forward arithmetic yet retain a long backward ready path. Final routed setup/hold must still pass; a completed native SDK command, valid CWC and spare resources do not substitute for timing. Three actual production attempts were used; stop before a fourth without new conditions.
12. One bounded DeepSeek text-accounting call was reviewed and rejected for dropped control/TD attempts and inconsistent totals. Native result JSON gave33 G1 runs,26 passes,7 failures. No worker operation/pending call_id existed; no resume or retry was fabricated.
