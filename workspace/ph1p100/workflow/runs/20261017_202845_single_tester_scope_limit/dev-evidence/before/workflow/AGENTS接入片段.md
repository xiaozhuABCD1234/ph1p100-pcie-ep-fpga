# 可选 AGENTS 接入片段

本项目根AGENTS.md已设置默认入口；本片段是同一逻辑的同步参考，迁移时只合并工作流段，必须保留原删除禁令、完整DeepSeek块及其他约束。仅对本项目生效，不改全局技能/配置，不授予外部动作权限。

```markdown
## 项目研发工作流

接收用户任务的主Agent首先读取 .agents/skills/fpga-orchestrator/SKILL.md。子角色直接读指定角色技能，禁止递归派生。主只原样保存/转发用户原话、路径、真实ID、判定和状态，机械维护日志并按简短dispatch执行固定分支；不理解技术需求/选题/设计/拆分，不读原始材料/完整计划/源码/报告，不开发/修复/测试/判断根因或复测影响/写技术总结。系统权限和路径范围检查仍执行。

规划者读任务相关材料理解拆分，确定task_id、依赖顺序、范围、三维验收/G层、工具设备、停止/回退，写完整计划和简短dispatch；主不从dev-plan选任务。默认每任务新开发和新三测试，不跨任务复用；只有用户明确批大小大于1才由规划定义批，每批一开发、三测试覆盖全批。

开发冻结manifest并停止修改后，同输入三测试并行。round0首次验收，最多三轮实际修复；同任务FAIL续原开发/测试，受修复影响的PASS维度按开发/测试清单续原测试，主不判断影响、不拼不同输入PASS。缺设备/工具/资料/用户输入或额度直接blocked交原规划备条件，主原样转用户，不空转三轮。必要验收不得放宽，仿真/构建/板测/长稳分账；文档配置事先限定静态复核，不跑无关硬件流程。

PASS、三轮未过或阻塞交原规划更新任务/dispatch、派发独立下一任务或写handoff/final-summary/用户短总结，主原样转发，开发写lessons。workflow/tasks.json及证据/交接保持主源，run控制文件不另立任务板，离线子包不把父硬件任务置done。缺输入/疑问/矛盾回原角色，范围验收归规划、复现报告归测试、实现归开发；用户反馈保持原话，无效或过长返回由原角色整理。

使用实际spawn_agent/followup_task/wait_agent/list_agents/send_message；fork_turns="none"传技能及输入路径，collaboration直接调用不放functions.exec，真实ID即时登记。send_message只送消息，空闲角色新轮用followup_task。原ID失效交规划按文件恢复并登记新旧映射，不假称resume；无多agent工具不得主接管。

AI/DeepSeek遵守根AGENTS和workflow/AI协作与工具接入.md的最小上下文/提案检查/原生执行/resume边界，不替代三个测试。禁止批量删除、不覆盖无关修改；不得扩大外部工程写入、下载位流、Flash、发布、外部/队友消息或自动化权限，不改全局配置。
```
