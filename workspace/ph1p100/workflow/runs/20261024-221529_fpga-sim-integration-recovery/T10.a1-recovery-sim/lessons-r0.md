# T10 round0 lessons

- 两项描述符数组配两位直接索引会在第三帧访问越界；前两个包正确不足以证明连续输入恢复。入口：固定 a1_uart_export 的 dq_wr/dq_rd 及 `defect-evidence.json`。
- 应同时核对 TB 计数标记、实际完整包数、严格 zlib/四 CRC/原像素和尾部。此处 CASE_PASS/exit0 与真实包错误并存，独立字节检查拒绝了错误通过。
- 中写复位须在真实部分 AW/W 接受且未发布时命中；W8/H2 的 RAW 只有一个 DDR 字，不能用估计时刻冒充外部多字中写。应由规划明确几何或入口定义，再执行未运行分支。
- DUT reset 不等于 DDR 接口队列 reset。模型保留已接受响应和存储，并记录 epoch；未真实运行 reset 用例时不可声明旧响应恢复已通过。
- ModelSim 10.5b 的命令行路径统一用正斜杠。首次载入失败保留日志，路径纠正后的实际仿真与启动错误分别记账。
