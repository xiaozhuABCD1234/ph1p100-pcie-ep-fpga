# DEFAULT-RELAY-V2 配置同步经验

- 触发：把“主只调度”保留成泛称时，旧说明仍容易把读计划、选题、复测判断、技术收尾回流给主。修正：明确可读简短dispatch/返回字段，由规划承担理解拆分和收尾，开发/测试给复测清单；入口与旧可选片段同步核对。
- 触发：把任何非PASS放入统一三轮循环，会对缺设备/工具/输入的状态空转。修正：blocked固定分支立即回原规划备条件；round1—3只计真实修复。
- 验证入口：`static-check.py`及`configuration.diff`覆盖本次静态格式/保护范围；配置语义与默认入口由三个独立静态测试报告判定，不将静态检查写成运行完整流程的证据。
