## 已获得的新结论

- 首次单路推荐表列1080p binning、RAW12、4lane×594Mbps、27MHz、20fps；后续比较594档推导30fps与891档表列30fps。旧配置的RAW10、24/27MHz混用和启动等待位置不能直接继承。依据Sony物理p49、59—61、80—81、89及相机报告中的源码定位。
- 接收参考不是完整可移植核：原语/时钟需PH1P适配，RAW12/CRC16/DT分流、尾字节、完整帧失效恢复和诊断需补齐。旧FIFO会满丢而未使整帧失效；auto delay的done不等于通过。依据17文件报告逐模块定位。
- 官方PH1P PCIe工程匹配当前器件，但测试RAM只有4KiB；发送状态机不含帧DMA。驱动bulk偏移及用户指针访问需修改/审查；DDR例程是控制器加测试发生器，不等于帧队列。依据整链路报告第5节。
- 推荐主传RAW12、FPGA三算法并行可切换验证、分块无损LZ77先过图集/吞吐门槛；BAR低速初验，C2H Memory Write作为实时搬运候选。无压缩率/吞吐/资源占用实测，不称已经冻结可部署方案。
