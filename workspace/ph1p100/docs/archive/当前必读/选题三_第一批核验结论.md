## 1. 本批确定的纠错

1. **10-09直接排除硬D-PHY的定论于10-10重开。** 用户提供系列/新品信息，Codex查到官方支持描述；同一官网SBG484选型行仍为“－”。当前优先定位硬D-PHY入口，旧本地包装白名单仅作版本/适配线索，不把矛盾写成硬核已可用。
2. **F9命名不能猜成PH1A。** MIPIIOF9F0D0P0的目录支持和RTL指向DR1，和F9P板名无关。
3. **PH1P100有HR输入差分/延时/解串资源。** HR输入delay为`PH1P_LOGIC_DYNAMIC_HR_IDELAY`、8bit/256 Step；不能按另一五位接口宣布只能扫0—31。PH1P100不支持该delay级联。
4. **T0—T3是DDR DQS分组。** 不直接等同clock region，也不能据同组标记宣布接收时钟必可用。
5. **1:10解串不是RAW10协议解包。** 字节对齐、多lane合并、CSI-2包校验和RAW10解包仍是后续层。

## 2. 当前路线

固定硬件继续保留，PCIe主通道不变。

```
IMX415实际HS/LP输出
  → VID006板级电气网络（待核实）
  → 优先核对硬D-PHY前端（SBG484/IP/球位资料冲突待定位；HRIO为备选）
  → 按实际IP边界补对齐/CSI-2校验/RAW12解包
  → 处理/压缩/缓存
  → PCIe
  → OrangePi解码/NPU
```

HR接收当前只是候选。HR LVDS输入的共模/输入电平有明确范围，LVDS18约束不能证明MIPI HS直连电气合规。
下一批追踪当前相机模组、VID006与F9P接线，之后再提交最小接收实验，不把厂商其他器件的bit或PnR报告当成当前硬件验证。
