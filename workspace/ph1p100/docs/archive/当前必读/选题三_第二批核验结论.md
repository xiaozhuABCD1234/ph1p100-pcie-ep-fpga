## 1. 电气路径：知道怎么连了，兼容性仍需验证

本轮解压CAM005硬件包，接口图和IO表确认FPC的数据/时钟、I2C、参考时钟、复位、VI_HS/VI_VS标签。
模组资料只包含连接器原理图Sheet5/5，实际实物版本及传感器内部连接仍需确认。

每条MIPI线通过VID006有两条不同支路：0Ω到B行，100Ω到A行。
更合理的软接收候选是B行HS差分接收＋A行LP单端观测，不能说两行可任意互换。
这类分离HS/LP的双路架构需约44—48个IO，而不是只按HS＋控制算28个。

HR LVDS共模/绝对输入范围和LVCMOS18门限需要对照实际源端。IO表的“1V1”是电源电压栏标签，不能当作HS共模或LP VOH的测量值；100Ω串阻也不是已证明的电平转换器。
端接控制以UG1310 §17.5真值表核对，不能只凭interm_disable的名字宣布禁用。当前真实端接、负载与电气条件未获实验验证。

## 2. 时钟路径：官方模板有明确起点，具体球位路由待实验

PH1P High Speed IO官方模板的EXTERNAL分支：
```text
相机返回逻辑时钟 → IOCLK → sclk
                 → 分频LCLK → pclk
```
选择1:8时pclk=R/8、sclk=R/2；HR输入delay为8位。
优先研究相机A的HS clock K18/K19、data0 N20/M20，先一lane再四lane；不能凭GCLK标记或DQS分组宣布专用路由已经合法。

IMX415模式、INCK与lane率必须一起配置。手册2×2 binning的1080p输出表写10bit ADC、12bit输出；旧示例的MDBIT=0与此不一致，不照搬。
初始验证可以低于目标速率，但必须用合法模式。读出RAW10/RAW12、HMAX/VMAX、lane数、INCKSEL与实际fps后再冻结配置。

## 3. 同步：已有A主、B从候选，不必由FPGA产生脉冲

CAM005 FPC16/17为VI_HS/VI_VS，VID006把两只相机这些脚通过共享网络连接，B侧各串100Ω。
若模组内部分别连到Sony XHS/XVS：
```text
相机A master → 共享HS/VS → 相机B slave
```
这是一条真实采集同步候选；“没有引到FPGA，所以只能SOF同步”的旧结论撤回。

关键配置依据：XMASTER主0/从1；30C1主输出00、从Hi-Z 0F。不能两只直接复制旧表，因为旧表两只都会配置成主机输出。
30C1为待机设置/退出待机反映的S类寄存器；角色/驱动设置须在退出待机前完成，不能靠工作中写Hi-Z保证立即关断。
退出待机等待至少24ms，开始同步后排除前8帧，从第9帧评估图像。

IMX415为rolling shutter；主从同步还需一致读出/行周期、参考时钟和曝光设置。SOF时间戳是辅助测量，不是曝光起点；对应行曝光偏差和共享波形仍待实测。

## 4. 下一步实验顺序

1. **低速控制/实物确认**：模组、排线、BANK13电压、INCK、RESETN、I2C读回。
2. **一lane数字最小实验**：官方IOCLK＋分频LCLK＋HR delay＋SERDES，实际球位、时钟映射与STA。
3. **电气与采样窗**：PAD电气/端接、8bit delay扫描、训练和重复启停。
4. **四lane协议接收**：对齐、ECC/CRC、RAW格式、行长/行数/溢出，验证连续正确帧。
5. **双路主从**：分角色初始化、共享XHS/XVS波形、共同时间基统计及采集/曝光同步验证。
