1. 双击 `TD_Release_2026.1_SP2_NL.exe` → 一路 Next 安装（默认路径即可）；

## 3. 装 JTAG 驱动（**最容易卡住的一步**）

### 3.1 接线
- **给板卡上电**；
- 用**一根串口线**连接 PC ↔ 板卡（**AFH03/Fmin01 的下载模块已集成在板上，JTAG 与 UART 复用**，所以一根线就够）。

### 3.2 装驱动
1. 解压 `UsbDriverTool.rar` → **以管理员身份**运行 `UsbDriverTool`；
2. 在列表里找到 **`USB Serial Converter A`**
   - 它的 **VID/PID = `0403/6042`**
   - （`USB Serial Converter A` 负责 USB→JTAG；另一个是 UART）
3. 右键该设备 → **`Install WinUSB`**；
4. 装完后设备名旁会显示驱动名 → 成功。

> 📖 课程 PDF **第 15~17 页**

### 3.3 在 TD 里连器件
1. 打开 TD → 打开 **BitWrite（下载）页面**；
2. Debug 模式选 **`AL-LINK-FT (Local Host)`**；
3. **`Local port` 填 `5555`** → 点 **Apply and Close**；
4. 点**芯片识别**：
   - ✅ 显示芯片型号（如 `PH1A90SEG324`）= 成功
   - ❌ `cable select` 空白 = 没连下载器
   - ❌ `0:0...IED` = 驱动没装上

> 📖 课程 PDF **第 18~23 页**

## 4. 跑通第一个例程

### 4.1 路线 A（推荐先做）：直接跑官方"开机测试" bit
`03_MLK_AFH03_AFC03\板卡资料\01_start\00_start_fpga\01_board_test\01_board_test.zip` 里有 6 个现成 bit：

| bit 文件 | 测试内容 | 现象 |
| --- | --- | --- |
| `01_uart_loop.bit` | UART 环路 | 串口回环 |
| `02_i2c_eeprom` | EEPROM 读写 | `Error` 信号不拉高 |
| `03_iic_rtc.bit` | RTC 读写 | — |
| `04_ddr3_axi_fdma_test` | DDR3 读写 | 逻辑分析仪看反馈，`Error` 不拉高 |
| `05_tpg_dsi_7cun.bit` | MIPI-TX 7 寸屏 | 屏幕出测试图 |
| **`06_csi_2_dsi_imx415_7cun.bit`** | **IMX415 相机 → 7 寸屏** | **屏幕出相机画面** |

**做法**：TD 下载页 → Add → 选 bit → Run（**先不要固化到 Flash**）。

> ⭐ **强烈建议先下 `06_csi_2_dsi_imx415_7cun.bit`** —— 这是**官方现成的 IMX415 方案**，直接验证你们的相机/排线/屏幕是否正常。

### 4.2 路线 B：自己建工程 + 点灯（在 Fmin01 上做）

**① 新建工程**
- Project Name：`fpga_prj`
- **Device Family：`PH1A`**（AFH03 用；Fmin01 按它自己的芯片选，见 Fmin01 文档）
- **Device Name：`PH1A90SEG324`**（AFH03）

**② 按米联客规范建目录**（在工程路径下建 `uisrc`）
```
uisrc/01_rtl    ← RTL 代码
uisrc/02_sim    ← 仿真
uisrc/03_ip     ← IP 文件
uisrc/04_pin    ← 引脚/时序约束
uisrc/05_boot   ← bit 输出
uisrc/06_doc    ← 文档
```

**③ 新建 verilog + 加 PLL IP**
- 参考课程里的例程（PLL + 计数器分频点灯）：
```verilog
module pll_test(
  input  I_sysclk,      // 系统时钟
  output [1:0] O_up_led // LED
);
  wire clk0, pll_lock;
  reg [25:0] cnt;
  ui_pll X_ui_pll_u(
    .reset(1'b0), .refclk(I_sysclk), .clk0_out(clk0), .lock(pll_lock)
  );
  assign O_up_led = cnt[25:24];
  always @(posedge clk0 or negedge pll_lock) begin
    if(!pll_lock) cnt <= 26'd0;
    else          cnt <= cnt + 1'b1;
  end
endmodule
```

**④ 加 IO 约束**：按**原理图**填 `Location` / `IOStandard`
- 需要 **`02_hardware/hardware_MLKPAI-FMin01-2025-06-11.zip`** 里的原理图找 LED 管脚
- 保存到 `uisrc/04_pin/fpga_pin.adc`

**⑤ 加时序约束**：加周期约束（如 25MHz → 40ns 周期），存 `uisrc/04_pin/timing.sdc`

**⑥ 一键编译** → 看 `Log Tree` / 资源利用 / 时序报告

**⑦ 出 bit**：右键 `Generate Bitstream` → `Properties` → 勾 **compress**、`boot_mode` 选 **`mspix4`** → 重新生成

**⑧ 下载**：Add bit → Run
- `PROGRAM` = 下载到 SRAM（掉电丢）
- `PROGRAM_FLASH` = **固化到 Flash**（掉电不丢）

> 📖 课程 PDF **第 24~53 页**（创建工程 / 加代码 / 加 IP / 约束 / 编译 / 压缩 / 下载）

## 附：常见卡点速查

| 现象 | 原因 / 解决 |
| --- | --- |
| TD 打不开 / 提示 license | `Anlogic.lic` 没放到 TD 的 `license` 目录 |
| cable select 空白 | 下载器没插 / 板子没上电 |
| `0:0...IED` | **WinUSB 驱动没装** → 重跑 UsbDriverTool |
| 找不到 `USB Serial Converter A` | 换 USB 口；换数据线（必须是数据线，不能是纯充电线） |
| 识别不到芯片 | 板子没上电；JTAG 模式没选 `AL-LINK-FT`；Local port 没填 5555 |
| 下载成功但没现象 | AFH03 **没有 LED**；看例程说明（如 UART/DDR 要用仪器看） |
