## 步骤 4｜⭐⭐⭐ 今天就验证 PCIe 通路（提前排掉最大的雷）

**为什么重要**：PCIe 是赛题第 4 项的硬要求，也是"关口③"。今天用现成 bit 就能验证硬件通路 + 你买的转接卡对不对。

**操作**
1. 把 **`12_pcie_gen2x2.bit`** 下载到 F9P
2. 接线：F9P **PCIe 金手指** → **M.2 转 PCIe 槽转接卡** → **OrangePi 5 Max 的 M.2 M-key**
3. **F9P 用自己独立的 12V 适配器供电**（M.2 只给 3.3V，带不动）；**两块板共地**
4. **先给 OrangePi 上电**，再给 F9P 上电
5. 在 OrangePi 上执行：
   ```bash
   lspci -nn                # 看有没有新设备
   sudo dmesg | tail -50    # 看有无 link up / PCIe 日志
   ```

**判定**
- ✅ `lspci` 出现一个新设备（哪怕是"未知设备"）→ **物理层 + 转接卡通！**
- ❌ 什么都没有 → 按顺序查：
  1. 转接卡是否引了 **REFCLK（100MHz）**
  2. **PERST#** 是否到位
  3. 两板是否**共地**
  4. F9P 金手指的供电脚是否需要外部 12V
- 📖 参考源码工程：`D:\TD\work\peripheral\12_pcie_gen2x2\`（看它怎么配的）
- 📖 手册：`D:\downlaod\Doc\IPUG\IPUG028_PH1P_PCIExpress_IP_Guide.pdf`

> 这一步过了，D18 的风险直接砍一半。

## 步骤 7｜硬件与接口核查（1~2 小时，画板级地基）

**7.1 抄子卡接线表**
1. 打开 `HW-FEP-VID006-MIPI-CSIX2.zip` → `02_原理图\fep-vid006-mipi-csix2-20250605.pdf`
2. 对照 v4 文档的映射（§2.3/§2.4），把 **CSI-A / CSI-B 每根线**做成表：
   `FEP针 → 信号名 → BANK13 对 → F9P FPGA 脚`
3. ⚠️ 重点标出 **A15/A16（相机 A 时钟）、A17/A18（相机 B 时钟）**

**7.2 生成 `constraints\board.adc` 草表**
- 对照 `HW-MLK-F9P-CA05-PH1P100.zip` → `09_pinlist\FEP-管脚定义表.xlsx`
- HS → `LVDS18`；LP / I²C / MCLK → `LVCMOS18`
- ⚠️ **先别写 `INDEL`**（那个值要后面扫出来，现在写错会误导）
- 📖 查 `D:\downlaod\Doc\SWUG\SWUG200_Timing_Constraints_User_Guide.pdf` 了解 `.adc` / `.sdc` 写法

**7.3 和 RK 队友开会定接口**（今天必须定）
要定：**Vendor/Device ID、BAR0 映射、DMA 地址宽度、MSI 向量数、帧头格式、缓冲归属、上电顺序**
