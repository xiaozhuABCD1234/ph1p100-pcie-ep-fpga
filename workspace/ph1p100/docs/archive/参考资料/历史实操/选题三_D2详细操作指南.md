## 🔴 2.2 FEP 电压实测（20 分钟）—— **上电前置门槛**

### 为什么必须做
BANK13 是 **HR-ADJ 可调电压 bank**，MIPI 的 HS 走 `LVDS18`、LP/I²C 走 `LVCMOS18` → **VCCIO 必须是 1.8V**。
设错 → 相机/子卡不工作，甚至损坏。

### 操作
1. **拔掉 12V 电源**（必须断电！改跳线带电会烧）
2. 看底板丝印，找 **FEP 电压跳线**（参考 `07_ADJ改电压说明\客户使用开发板其部分BANK供电电压说明.txt`）
3. 把跳线帽拨到 **1.8V** 那一档
4. 上电
5. **万用表直流档**量：
   - 首选：**BANK13 的 VCCIO 测试点**（看底板丝印/核心板手册）
   - 备选：FEP 连接器附近 1.8V 相关测试点
6. 记录数值

### 验收
- ✅ **≈1.8V**（1.75 ~ 1.85V 都算正常）
- ❌ 量到 2.5V / 3.3V → **跳线没拨对**，重来
- ❌ 量到 0V → 板子没上电或测错点

### 填入
`D:\TD\work\csi2\docs\bringup.md` 的「2.2 FEP 电压实测」表格

## 🔴 2.3 PCIe 物理通路验证 ⭐（40 分钟）—— **D2 门槛**

### 为什么这是 D2 最高优先
这是**唯一能独立验证「F9P 金手指 + M.2 转接卡 + OrangePi M.2」这条物理链路对不对**的手段。
只用官方现成 bit，30~40 分钟。**如果不通，后面 D3–D5、D17–D18 全要改路线。**

### 硬件接线
```
F9P 底板 PCIe 金手指
      │
      ▼
【M.2(公) → PCIe x4 母槽】转接卡        ← 你已买的那块
      │
      ▼
OrangePi 5 Max 的 M.2 M-key 插座
```
**供电**：
- F9P 用**自己独立的 12V 适配器**（M.2 只给 3.3V，带不动）
- **两块板必须共地**（如果转接卡没共地，飞一根地线）

### 操作步骤
1. 板子上电，Type-C 连 PC
2. TD → **Tools → Download / BitWizard**
3. 选 `D:\TD\work\bits\12_pcie_gen2x2.bit` → **Program**
4. 接线：F9P 金手指插入转接卡的 PCIe 槽；转接卡 M.2 公头插入 OrangePi 的 M.2 座
5. **先给 OrangePi 上电**，**再给 F9P 上电**
6. 在 OrangePi 上执行：
   ```bash
   lspci -nn
   ```
   找到类似 `01:00.0 Memory controller [0500]: ... [1edb:abcd]` 的行
7. 再看链路状态：
   ```bash
   lspci -vv -s 01:00.0 | grep -E "LnkCap|LnkSta|BAR"
   ```

### 验收标准
| 看到什么 | 判定 |
|---|---|
| 有设备 + **`LnkSta: Speed 5GT/s, Width x2`** | ✅ **通**，可以进 D3 |
| 有设备 但 `Width x1` | ⚠️ 转接卡只连了 1 lane → **换转接卡** |
| 有设备 但 `Speed 2.5GT/s` | ⚠️ 只协商到 Gen1 → 先记下，D4 再查 |
| **什么都没有** | ❌ **停！** 按下面排查 |

### 排错表（什么都没有时，按顺序查）
| # | 检查项 | 怎么查 |
|---|---|---|
| 1 | **共地** | 万用表量 F9P 的 GND 与 OrangePi 的 GND 是否导通 |
| 2 | **F9P 是否真的上电** | 看板上 LED 有没有亮 |
| 3 | **转接卡是否引了 REFCLK（100MHz）** | 问卖家 / 看转接卡有没有 100MHz 晶振 |
| 4 | **PERST# 是否到位** | 转接卡要引 M.2 的 PERST# 到 PCIe 槽的 A11/B11 |
| 5 | **lane 数** | 有些廉价转接卡只连 x1 |
| 6 | **上电顺序** | 试试「先 F9P 上电，再重启 OrangePi」 |
| 7 | **换一个 M.2 槽 / 换台 PC 试** | 用 PC 的 PCIe 槽验证 F9P 是不是 EP 问题 |

### 填入
`docs\bringup.md` 的「2.3 PCIe 物理通路」表格（**粘贴 `lspci` 原始输出**）
