# 【阶段 1】安装 TD + 放 license（约 1 小时）

## 1.1 运行安装程序
1. 双击 **`TD_Release_2026.1_SP2_NL.exe`**；
2. 出现标题为 **`TD_Release_2026.1 安装`** 的向导窗口；
3. 第一屏：**「欢迎使用 TD_Release_2026.1 安装向导」** → 点 **`下一步(N) >`**。

## 1.2 选择安装文件夹
出现 **「选择安装文件夹」** 页：
- 默认路径形如 `D:\Anlogic\TD_Release_2026.1_6.2.190.657\`
- **建议保持默认**（或改成纯英文无空格路径，如 `D:\Anlogic\TD2026`）
- 点 **`下一步(N) >`**

> ⚠️ **绝对不要用中文路径**，TD 会在综合时报奇怪的错。

## 1.3 最终用户许可协议
出现 **「最终用户许可协议」** 页：
- 选 **「我接受许可协议中的条款(A)」**
- 点 **`下一步(N) >`**

## 1.4 继续 Next 到安装完成
- 后续页面一路 `下一步(N) >`
- 安装过程 **约 10~20 分钟**（1.9GB）
- 完成后点 `完成`

## 1.5 放 license（★ 不做这步 TD 用不了）
1. 打开 TD 安装目录（如 `D:\Anlogic\TD_Release_2026.1_6.2.190.657\`）；
2. 里面应有一个名为 **`license`** 的文件夹；

## 1.6 验证 TD

2. 主界面标题栏显示 **`TangDynasty 6.2.1`**；
3. 界面分两块：
   - **左：`Work With a Design`** → `New Project` / `Open Project` / `Open Board Example Design`
   - **左下：`Work With a Tool`** → `BitWriter` / `ChipWatcher` / `Encrypt Tool` / `Language Template`

# 【阶段 2】Fmin01（便宜板）：装驱动 → 识别芯片 → 第一个 bit（约 2 小时）

## 2.1 装 AL-LINK 驱动
1. 解压 `driver.zip` → 得到 `al-link\` 目录；
2. **先不插线**，先打开**设备管理器**留个底；
3. 用 **一根 Type-C 数据线**把 Fmin01 连到电脑（板子自动上电）；
4. 设备管理器里会出现一个**带黄色感叹号的未知设备**；
5. **右键该设备 → 更新驱动程序 → 浏览我的电脑上的驱动程序 → 让我从可用列表中选择** → 指向：
   ```
   al-link\win10(win11)\x64\
   ```
   （若是 Win7，选 `al-link\win7\x64\`）
6. 装完后，设备管理器里应出现 **`AL-LINK`** 类设备，无感叹号。

✅ **完成标准**：设备管理器能看到 AL-LINK 设备，无黄色感叹号。

> ⚠️ Fmin01 是 **一根 Type-C 线同时给 JTAG + UART + 5V 供电**。

❌ 装不上怎么办：
- 用"从磁盘安装"手动指定 `anlocyusb.inf`
- 换一个 USB 口（优先主板后置的 USB2.0 口）
- 换一根 **Type-C 数据线**（很多线只供电不传数据）

## 2.2 在 TD 里识别芯片
1. 打开 TD；
2. 点 **左下的 `BitWriter`** → 打开下载窗口；
3. 点工具栏的**下载按钮**（左上第一个图标）→ 弹出 **`Debug Server Setting`** 对话框；
4. `Mode Select` 选 **`AL_LINK`**（Fmin01 用老的 AL-Link）；
5. 点 **`Refresh`** → 看 `Cable Select` 下拉框；
6. 点 **`Apply and Close`**；
7. 回到 BitWriter，点 **`Refresh`** → **应显示芯片型号（`EG4D` 之类）**。

✅ **完成标准**：BitWriter 里能看到芯片型号。

❌ 对照表：
| 现象 | 含义 | 处理 |
| --- | --- | --- |
| `Cable Select` **空白** | 电脑没连下载器 | 检查线/口 |
| `0:0...IED` | **驱动未识别** | 重做 2.1 |
| 识别不到芯片 | 板子没上电/模式选错 | 换线换口；模式确认 |

## 2.3 下载第一个 bit（`01_key_led.bit`）
1. 解压 **Fmin01 的 `01_board_test.zip`** → 得到 7 个 `.bit`；
2. BitWriter 窗口：
   - `Mode Selection` 的 `Mode` 保持 **`PROGRAM_SRAM`**（下载到 SRAM，掉电丢，**调试阶段用这个**）
   - `Speed` 保持默认（如 `5MHz`）
3. 点左侧 **`Add`** → 选择 **`01_key_led.bit`**；
4. 点左侧 **`Run`** → 看进度条到 100%。

✅ **完成标准（现象）**：
- **上面的按键** → 控制 **4 个 LED 流水**
- **下面的按键** → **复位**
- **4 个拨码开关** → 控制其余 **4 个 LED** 亮灭
- **蜂鸣器** 3kHz 啸叫

🎉 **看到以上现象 = 环境完全打通。**

# 【阶段 4】自己建工程：TD 全流程（逐对话框）★最重要

> 目标：不看教程也能建工程 → 加代码 → 加 IP → 加约束 → 编译 → 下载。
> 这一步学会，以后画板/写软 D-PHY 全靠它。

## 4.1 新建工程
1. TD 主界面 → 左侧 `Work With a Design` → 点 **`New Project`**；
2. 弹出 **`New Project Wizard`** 对话框，逐字段填：

| 字段 | 填什么 |
| --- | --- |
| `Project Name` | `fpga_prj` |
| `Project Path` | 点 `Browse...` 选 `D:\FPGA\03_我的工程\` |
| **`Device Family`** | **`PH1`**（AFH03；Fmin01 选它自己的系列） |
| **`Device Name`** | **`PH1A90SEG324`**（AFH03；Fmin01 选 EG4D 之类） |
| **`Device Speed`** | **`-2`** |

3. 点 **`OK`** → 空工程创建完成。

> ⚠️ **Device Family 是 `PH1`**（不是 `PH1A`）—— 按截图填。

## 4.2 建目录规范（在工程目录下）
```
fpga_prj\uisrc\
  01_rtl     ← RTL 代码
  02_sim     ← 仿真
  03_ip      ← IP 文件
  04_pin     ← 引脚(.adc)/时序(.sdc)约束
  05_boot    ← bit 输出
  06_doc     ← 文档
```

## 4.3 新建 Verilog 源码
1. 右键左侧 **`Hierarchy`** → 菜单里选 **`New Source`**；
2. `File Type` 选 **`verilog`**；
3. `File Name` 填如 `pll_test`；
4. `Location` 指向 `uisrc\01_rtl`；
5. **只有一个文件时默认就是 Top**；多个文件时右键文件名 → 设为 Top。

## 4.4 加 PLL IP 核
1. 菜单 **`Tools → IP Catalog`**；
2. 分类里选 **`PLL`**（本次例程用）；
3. 弹窗里设 **IP 存储路径**和 **IP Name**（如 `ui_pll`）；
4. 配置时钟（输入频率、输出频率）；
5. **勾选生成 `.v` 文件**；
6. 例化：右键 PLL 的 `.v` → **`Show Instantiation Template`** → 复制模板 → 粘到顶层 → 改名/连线 → 保存。

**例程代码（可直接抄）**：
```verilog
module pll_test(
  input  I_sysclk,      // 系统时钟输入
  output [1:0] O_up_led // LED 输出
);
  wire clk0, pll_lock;
  reg [25:0] cnt;

  ui_pll X_ui_pll_u(
    .reset    (1'b0),     // PLL 复位
    .refclk   (I_sysclk), // PLL 输入时钟
    .clk0_out (clk0),     // PLL 输出时钟
    .lock     (pll_lock)  // PLL 锁定
  );

  assign O_up_led = cnt[25:24];

  always @(posedge clk0 or negedge pll_lock) begin
    if (pll_lock == 1'b0) cnt <= 26'd0;
    else                  cnt <= cnt + 1'b1;
  end
endmodule
```

## 4.5 添加 IO 约束（PIN 脚）
1. **先点一次综合（Synthesis）** —— ⚠️ **必须先综合，才能做 IO 约束**；
2. 打开 **`Anlogic IO Constraint`** 窗口；
3. 下部表格列（照实拍照抄）：
   `Name | Direction | Bank | Location | IOStandard | DriveStrength | PullType | PreEmphasis | SlewRate | DiffResistor | ODT | PCIClamp`
4. **对照原理图**填：
   - `Locatioin` ← **重点**，从原理图找 PIN 号
   - `IOStandard` ← 单端一般 `LVCMOS33 / LVCMOS25 / LVCMOS18`
   - 其他默认
   - 高速应用才需要设 `InDelay/OutDelay/SlewRate`
5. 原理图位置：
   - Fmin01：`01_Fmin01\` 里的 `hardware_MLKPAI-FMin01-*.zip` 解压后的原理图
   - AFH03：`02_AFH03\` 里的 `MLK-AFH03-20251112.pdf`
6. 点**保存** → 存到 `uisrc\04_pin\fpga_pin.adc` → 提示是否加入工程 → **Yes**。

> ⚠️ **AFH03 没有 LED 和按键** —— 官方课程原文："AFH03 由于FPGA 的IO 数量有限，未设计led 与按键,故此实验无法进行上板验证"

## 4.6 添加时序约束（时钟周期）
1. 先双击**综合**；
2. 打开 **`Timing Wizard`**（或 `Tools → Timing Constraint`）；
3. 左侧树展开 `Clocks` → 双击 **`Create Clock`**；
4. 弹出 **`Specify Object Source`**：
   - `Collection` = `get_ports`
   - `Filter` 填 `*` → 点 **`Find`**
   - 在 `Matches` 里选时钟信号（如 `I_sysclk`）→ 点 **`>`** 移到右侧
   - 点 **`Ok`**
5. 回到 **`Timing Wizard`**：
   - `Clock Name`：`sysclk`
   - `Waveform → Period`：按实际频率填（**25MHz → 10.000 ns**）
   - `Rise` = `0.000`；`Fall` = `5.000`
   - 底部 `Command` 栏会自动生成：
     `create_clock -name sysclk -period 10.000 -waveform (0.000 5.000) [get_ports {I_sysclk}]`
   - 点 **`Ok`** → 再点 **`Apply`**
6. **PLL 输出的时钟也要单独约束**（`Create Generated Clock` 或再加一条 `create_clock`）；
7. 保存时序约束到 `uisrc\04_pin\timing.sdc`。

> 💡 若左侧框无信号显示：在 `Filter` 输入 `*` 回车查找。

## 4.7 一键编译 + 看三个报告
1. 点**一键编译**；
2. 编译完看：
   | 报告 | 看什么 |
   | --- | --- |
   | **`Log Tree`** | 有没有 **Error**（Warning 可先忽略） |
   | **资源利用报告** | LUT / DFF / BRAM(ERAM) / DSP / PLL —— **以后要填进测试报告** |
   | **时序分析报告** | 有没有 **Timing Violation**（违例） |

## 4.8 生成 bit（可选：压缩）
1. 右键 **`Generate Bitstream`** → **`Properties`**；
2. 勾选 **`compress`**；
3. `boot_mode` 选 **`mspix4`**（固化到 Flash 后启动更快）；
4. 保存并关闭 → **重新生成 bit**；
5. 输出在工程的 `05_boot` 目录（名如 `fpga_prj.bit`）。

## 4.9 下载
1. `BitWriter` → `Add` 选 bit；
2. `Mode Selection`：
   - **`PROGRAM_SRAM`** = 下到 SRAM，**掉电丢失**（调试用）
   - **`PROGRAM_FLASH`** = **固化到 Flash**，掉电不丢
3. 点 **`Run`**。

## 4.10 学 ChipWatcher（在线逻辑分析仪，**调试 MIPI 时的唯一"眼睛"**）
1. 工程已编译后：`Tools → IP Catalog → Debug → ChipWatcher`；
2. 设 `Number of Probes`（1~256）、`Sample Data Depth`（128~65536）；
3. 例化到工程 → 重新编译 → 下载；
4. 点 `ChipWatcher` → **`Watch`** → `Add Signals` 加信号 → 设触发条件（rising/falling/edge…）→ **触发** 看波形。

✅ **完成标准**：能独立走完 4.1~4.9，并用 ChipWatcher 抓到一次波形。

# 【阶段 5】切到赛题板 AFH03（约半天）

## 5.1 换 JTAG 驱动（**和 Fmin01 不是同一套！**）
| | Fmin01 | **AFH03** |
| --- | --- | --- |
| 下载器 | AL-LINK | **AL-LINK-FT（OneCable）** |
| 驱动方式 | `anlocyusb.inf` | **`UsbDriverTool` 装 WinUSB** |

**操作（逐步骤）**：
1. **以管理员身份**运行 **`UsbDriverTool`**（解压自 `UsbDriverTool.rar`）；
2. 给 **AFH03 上电**，用 **一根 Type-C 数据线**连 PC（**JTAG 与 UART 复用**）；
3. 窗口标题 **`USB Driver Tool`**，列 `Device Name | Vendor ID | Device ID | Interface`；
4. 找到 **`USB Serial Converter A`**：
   - `Vendor ID` = **`0403`**
   - `Device ID` = **`6042`**
   - `Interface` = **`00`**
5. **右键该行** → 菜单里选 **`Install WinUSB`**；
   （菜单还有 `Install Android ADB Driver` / `Install FTDI CDM` / `Install Libusb - WinUSB` / `Restore default driver`，**别选错**）
6. 装完后该行会变成 **`USB Serial Converter A (WinUSB)`** ✅

> ⚠️ **两套驱动可能冲突** → Fmin01 和 AFH03 **用不同 USB 口**，或**每次只插一块板**。

## 5.2 TD 里换模式
1. `BitWriter` → 下载按钮 → 弹 **`Debug Server Setting`**；
2. `Mode Select` 选 **`AL-LINK-FT(Local Host)`**；
3. `Local Port` 填 **`5555`**；`JTAG CLK Freq` = `12MHz`；
4. 点 **`Refresh`** → `Cable Select` 会显示 **`0:AL95XX91`**（你板子的真实序列号）；
5. 点 **`Apply and Close`**；
6. 回到 BitWriter 点 `Refresh` → **应显示 `0:PH1A90`**。

✅ **完成标准**：识别到 `PH1A90`。

## 5.3 跑 AFH03 的官方 6 个 bit
解压 AFH03 的 `01_board_test.zip`，逐个 `Add → Run`：

| bit | 现象 |

| `02_i2c_eeprom` | EEPROM：`Error` 不拉高 |

| `04_ddr3_axi_fdma_test` | DDR3 读写：`Error` 不拉高（用逻辑分析仪看） |

> ⚠️ **AFH03 没有 LED/按键** → 别指望点灯；用 **HDMI/屏/串口/仪器** 看现象。
> ⭐ **重点跑 `06_csi_2_dsi_imx415_7cun.bit`** —— 官方现成的 IMX415 方案，直接验证你们的相机/排线/屏。

## 5.4 在 AFH03 上跑一次自己的工程
