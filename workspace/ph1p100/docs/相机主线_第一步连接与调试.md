## 1. 当前只做这一条主线

PC/TD下载与ChipWatcher → F9P/PH1P100 → VID006的A接口 → 一只CAM005。

顺序是连接 → 最小控制工程/寄存器读回 → 相机出流/单lane接收 → 四lane与CSI/RAW12 → 本地缓存/图像检查。处理、压缩、PCIe及RK随后接入。已有TD、下载、ChipWatcher和HDMI/DDR使用经验直接沿用。

首个里程碑是相机ACK并正确读回寄存器；下一里程碑是正确真实图像。软件压缩模型和队友RK交付不再挡在这两个里程碑前面。第一只出图后再扩展到双路。

## 2. 现在可执行：只接A路

1. 关闭F9P电源并断开可能供电的USB连接，插接期间保持断电。
2. 将VID006的FEP连接器与F9P的FEP座对正，按连接器防呆/定位结构插到位，固定板卡。沿用此前已处理的FEP 1.8V跳线；不改成3.3V。相机模组输入供电3.3V与控制IO 1.8V是两个不同概念。
3. 在VID006上找到丝印 **MIPIA-CSI**，对应原理图 **U5**。先只接一只CAM005；B口留空。
4. 使用随套餐提供、适配CAM005的40芯排线：打开锁扣，确认两端裸露触点与插座内部接触片相接，排线平直插到底，再锁好。以插座触点和厂家实际装配说明确定方向；现有本地手册未给排线装配照片，不能由结构图推断“蓝面向上”或“两端同面”。尚未认清触点时先保留断电，近照核对即可，不需要先做仪器测试。
5. 沿用已跑通的PC下载器连接。暂不连接RK和PCIe；仪器留到控制信号或接收出现具体问题时再使用。
6. 接好后记录“A口、单CAM005、排线已锁、FEP电平沿用1.8V”。这就完成当前连接步骤；随后进入最小相机控制工程，不重跑点灯、HDMI或DDR基础课。

本次不把“先独立测一遍全部电压/高速波形”安排成研发前置任务。连接方向、电平选择等是插接动作本身的一部分；已知状态直接沿用，出现具体异常再针对定位。
