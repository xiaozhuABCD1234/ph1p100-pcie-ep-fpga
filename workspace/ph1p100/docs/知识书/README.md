# FPGA 方案知识书

> 把本项目**现行 FPGA 方案**拆成细碎的基础知识，由浅入深、书式分章，辅以网上优质视频与文档；目标是让读者对方案的关键取舍做出**自己的判决**（示例：DDR1600 / 1333 / 800E 到底差在哪、什么时候该选谁）。

- 建书任务：`workflow/runs/20261017_162355_fpga_knowledge_book`（KB0 建骨架与样章；KB1–KB6 写正文；KB7 收束：第 27 章＋附录 90/91/92＋全书终版）。
- 本文件角色：书首页（目的 / 阅读路线 / 目录与进度 / 维护规则 / 与旧教材的关系）。终版已由收束包 KB7 刷新（2026-10-18）。
- 语言与来源：中文正文、术语中英对照；外部资源中文优先，英文权威源作深入补充。

## 这本书为谁写、想解决什么

- 读者：项目参与者本人（以及未来接手的人）。假设你能读懂基础代码和数字常识，但不要求先背寄存器或读完某本教材。
- 目标：把"我们这么设计"翻译成"为什么可以这样、证据到哪一层、什么时候可能不成立"；读完重要章节后，能对方案的关键选择给出有依据的判断，而不是只记住结论。
- 不做：不替代项目任务板（`../../workflow/tasks.json` 中 T01–T14 的状态独立记账）；不改变任何已冻结决策；不替组织方口径或未决事项拍板。

## 两条阅读路线

1. **顺序精读**（推荐第一次这样读）：从 Part 0 到 Part 6，按第 01 → 27 章顺序。每章结构相同——先读"10 分钟速读卡"，再读正文，最后做自测题。
2. **判决速查**（带着具体问题来）：先查 [90_决策索引.md](90_决策索引.md) 或[第 27 章](27_如何做出自己的判决.md)，再跳到相关章节。跨章引用一律写成"见第 N 章"。

- 正文各章由对应工作包（KB1–KB6）的开发者按同一模板写作，**包与包之间不得互相修改对方章节**。
- 本文件（README）、`_写作规范.md`、`_全书大纲.md` 由 KB0 建立；**各写作包可有界更新 README 中本包章节的目录/进度行与"当前快照"句，其余内容一律不得修改**；收束包（KB7，原称 KBZ 的计划已按用户收敛指令合并）统一复核并刷新终版与附录。
- 模板、大纲、写范围的任何变更：交规划者裁定（范围变更），不在书内私自改。
- 每章冻结后按 manifest 停止修改；发现错误按下一次修订轮更新，并在该章"版本记录"写一句变更。
- 进度表刷新时点：每包交付时由该包**有界刷新**本包章节行与"当前快照"句（KB7 终版统一复核）；中途进度快照以 `../../workflow/runs/20261017_162355_fpga_knowledge_book/` 内记录为准。

## 与既有教材的关系

- 旧教材：`../../当前必读/01_FPGA主线学习手册_由浅入深.md`（初版 2026-10-09，顶部含 10-10/10-13 更新条目）。它建立了本项目"由浅入深"的讲法，可先读它建立整体印象。
- 但旧教材的部分主线口径（如 RAW12、LZ77 主线、RGB565 主线）已被后续工作更新为历史口径；**本书按现行方案基线重新组织**（RAW10 packed、LZ77 基线＋Bayer 优化、R10F 传输等）。
- 旧教材保持原样、不修改；两处表述冲突时，以本书与现行项目文档（任务记录、决策登记、证据目录）为准。
