## 4. 电气：路径已知，兼容性未关闭

### 4.1 已有接收端限制

D1 HR LVDS：单端输入0.45—1.725V，共模0.5—1.4V，差分摆幅100—600mV（PDF75/印刷69）。
HR LVCMOS18的低门限最大0.35×VCCIO，高门限最小0.65×VCCIO；VCCIO=1.8V时分别为0.63V、1.17V（PDF72/印刷66）。

C2将MIPI相关针列为1V1，**这既不能当成HS共模=1.1V，也不能单凭该栏确认LP高电平=1.1V**。
必须用源端完整MIPI电气规格、实际PAD波形和接收配置，验证：
- HS的P/N单端值、共模、差分摆幅是否在HR规格内；
- LP高/低与LVCMOS18门限是否留有裕量；
- 0Ω/100Ω分支、片内端接、上拉和未使用引脚的配置如何影响源端；
- burst启停和LP→HS转换时是否有足够稳定/训练时间。

相机控制1V8、电源调到1.8V、或者参考板使用LVDS18，均不能单独解决这组问题。

### 4.2 端接不能照模板默认推断

V1的150Ω并联电阻标NC，不等于已具备外部HS端接。
官方HSIO模板在差分输入分支（`High_Speed_IO.v`行644—655）设置`DIFF_TERM="TRUE"`且将`interm_disable`接`1'b1`。
独立复核发现：**不能只凭端口名推断这个组合禁用端接。** UG1310物理PDF60/印刷42、§17.5的真值表把0/TRUE、0/FALSE、1/TRUE列在“使能端接”组，仅1/FALSE列在“禁用端接”组。
按该版真值表，模板的TRUE＋1组合应属于使能；当前工具/库和最终物理配置仍须核验。不据旧名称推断增加外部端接，也不把模板当作已验证的MIPI LP/HS端接管理。
后续最小实验须明确谁提供HS端接、参数与动态控制如何配合、LP期间负载，并核对实际映射。

## 5. 真实同步：A 主、B 从的现有通路候选

### 5.1 共享网络是关键新证据

V1 PDF2：
```text
U5.16 ─ HS ─ R147(100Ω) ─ U6.16
U5.17 ─ VS ─ R148(100Ω) ─ U6.17
```
HS/VS没有引到FEP，但CAM005定义16/17为VI_HS/VI_VS。
若内部确实分别连接Sony XHS/XVS，则**相机A主机输出→共享网络→相机B从机输入**可实现传感器同步，不需要FPGA主动发同步脉冲。
前文“未引到FPGA，所以只能SOF同步”的结论撤回。

### 5.2 Sony 配置依据（C3 PDF65/印刷65）

| 地址 | 功能 | 主机A候选 | 从机B候选 |
|---|---|---|---|
| 0x3003 bit0 | XMASTER | 0：master | 1：slave |
| 0x3002 bit0 | XMSTA | 1待启动，0开始 | 不拿此项代替外部XHS/XVS |
| 0x30C0 | XVSOUTSEL/XHSOUTSEL | 0x2A选择两同步输出 | 保留合法固定字段 |
| 0x30C1 bits0..3 | XVS_DRV/XHS_DRV | 0x00使能两输出 | 0x0F使两驱动Hi-Z |
| 0x30CC/0x30CD bits5:4 | XVS/XHS低脉宽 | 按模式和时序要求设置 | 接收主机脉冲 |

30C1默认0x0F；但上电未清除前寄存器未定义（C3 PDF85）。30C1为S类（PDF40）；PDF32明确S类在待机期间设置、退出待机后反映，不能假定运行中写0x0F立即关断。主从角色及驱动配置必须在退出待机前完成。
C3 PDF65要求不能在工作中切换XMASTER。同页“取消system reset前建立XMASTER状态”的措辞，与PDF88图中系统清除后写寄存器的顺序存在歧义；实现前需结合模组/厂家确认。当前候选按图88/89在退出待机、启动流之前完成角色配置，不给出在硬件清除期间写寄存器的处方。

**跨平台示例不能直接复制到两路：**
`D:\TD\03_MLK_AFH03_AFC03\板卡资料\03_course\07_异构方案\415_mipi\uisrc\03_ip\ui_imx415_cfg\ui_imx415_reg.v`
行49写3003=00，行105—106写30C0=2A、30C1=00。
若两只相机都采用此主机输出配置，共享网络可能发生输出冲突。因此新的配置模块必须区分相机角色。

### 5.3 初始化与测量条件

- 实际SENSOR_RSTN/INCK内部连接需先确认；清除后先保持两路输出禁用，从机Hi-Z、主机待启动。
- 两路使用同一连续参考时钟源，频率及INCKSEL按选定模式表匹配；不把相机MCLK和两路独立返回的HS clock混为一根时钟。
- 配置相同读出模式、行周期、帧周期、读出方向与对应SHR0；曝光更新要有一致时序。
- 从机退出待机后至少24ms再输入同步；主机退出待机后等待至少24ms再开始（C3 PDF85、88、89）。随后前8帧是初始化期，从第9帧起评估有效图像（PDF64），不以刚开始出帧当作稳定。
- 为配合从机等待，先准备B，再启A；最终具体时序在配置实施计划中展开，不在本轮直接驱动硬件。
- 从机XHS高/低至少各4个INCK周期；PDF18图示的`tHFDLY`、`tVRDLY`各至少1个INCK周期，不能泛化为任意边沿间隔。上升20%→80%、下降80%→20%的时间≤5ns；共享网络实际波形需测。

### 5.4 同步不等于有效像素位置

C3 PDF18、66说XHS/XVS不能标记有效像素的准确位置，输出数据相对XHS有未定义系统延迟，因此按CSI同步码定位。
这句话**不否定主从采集同步能力**。
C3 PDF70—71明确rolling shutter及逐行积分时间；真实同步目标应定义到对应行/帧，并保持读出和曝光参数一致。
共同时间基的SOF统计是辅助证据，不是曝光时刻本身；NPU到帧时间不能当作传感器曝光开始。

## 6. 从“候选”转成“通过”的最小证据

1. 两只实物确为对应CAM005版本、排线规格/方向正确；本地参数文件写赠送40pin反向排线，不能只按两端视觉位置对针。
2. 模组内部四条控制/同步信号连接，或厂家书面确认/实物连续性。
3. 0Ω/100Ω及R147/R148实装、电压和信号路径确认；断电量电阻，上电才量电压/波形。
4. HS/LP PAD电气及端接符合接收条件；若测量仪器无法覆盖所选速率，明确限制并寻求相应电气依据。
5. 最小接收实验合法时钟/PnR/STA、重复稳定采样窗、CSI错误与丢帧统计。
6. 主从寄存器读回、共享XHS/XVS波形、共同测量时基下多帧偏置及曝光/行同步验证。
