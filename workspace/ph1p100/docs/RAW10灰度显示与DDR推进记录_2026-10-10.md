## 1. 现在的链路与这次修复

现有链路为 IMX415 → HRIO 软 PHY → 字节/通道对齐 → CSI 包解析 → RAW10 解包 → A 路缩小为 960×540 灰度 → 片内 ERAM → 放大至 1920×1080 → HDMI。当前黑白来自预览将灰度复制到 RGB，并非据此判定相机没有彩色信息。首版暂不增加 Bayer 去马赛克。

当前帧缓存是片内 ERAM，占用 224/300 块，没有接外部 DDR。单帧存储边写边读缺少帧所有权，可能撕裂；加入 DDR 的主要目的，是保存完整帧并分离采集与显示的节奏。

## 4. DDR 首版接入设计

第一步只缓存 **A 路 960×540、8bit 灰度预览**。这能直接解决显示的帧归属问题，之后扩展到全分辨率 RAW10 双路队列。不能将首版灰度缓存写成已经保存完整 Bayer/双路原图。

候选数据通路：缩小灰度流 → 32 字节打包 → 异步写 FIFO → DDR 用户域写入完整帧 → 三槽帧管理 → DDR 预取 → 异步读 FIFO → HDMI。将缩小模块与现有 ERAM 读写拆开，原来占用大量 ERAM 的单帧缓存由 DDR 替代，片内仅留行缓存/FIFO。

三槽分别为写入中、待显示、显示中；每槽 518400 字节，总计 1555200 字节。每行 30 个 256bit beat，每帧 16200 beat。30 fps 写入为 15.552 MB/s；候选 30 Hz 显示读取同为 15.552 MB/s，合计净流量 31.104 MB/s，不含刷新、仲裁及总线开销。若恢复 60 Hz，合计变为 46.656 MB/s。

必须遵守：仅完整且无错误的帧进入待显示队列；显示只在帧边界交换槽；没有新帧重复上一完整帧；采集不可反压，溢出时丢整帧并计数，不能发布半帧。读 FIFO 下溢不能暂停 HDMI 时序，应输出受控灰度/黑场并记录错误；正常预取必须保证有效区不断供。复位/DDR 校准未完成时禁止发起用户访问。
