## 正常预期

| 项目 | 正常现象 |
|---|---|
| 显示档位 | 始终为1920×1080、60Hz；图案切换时显示器无需重新识别信号 |
| 相机模式 | 原960×540 Gray8预览经现有显示链路输出；相机采集仍为4K30，不代表已经完成1080p60采集 |
| 图案左上 | 从黑到白的重复细灰度斜坡 |
| 图案右上 | 很细的黑白棋盘；肉眼可能因屏幕像素和观察距离呈灰色或纹理 |
| 图案左下 | 水平方向延展的分级灰度横带 |
| 图案右下 | 固定的细灰度纹理 |
| 图案颜色 | RGB三通道相等，设计上只有灰度；活动彩点不是预设效果。手机拍摄的摩尔纹/反光不能独立作为彩点证据 |
| LED | D37为DDR就绪后的心跳；D38常亮代表曾至少一次读回校验通过；D39应灭；D40为A配置完成。D38亮不证明每帧正确，D39灭也不覆盖所有潜在物理错误 |

若D39亮，记下它并停止将该次结果当成“已监控错误均未发生”的比较；不自行更改曝光、延时tap或PLL相位。

## 如何解释结果

| 同次运行的结果 | 下一步定位方向 | 不能得出的结论 |
|---|---|---|
| 相机有彩点，灰度图也有彩点 | 优先查共同的HDMI编码后链路、串行器/时钟、电气与速率支持；结合错误计数判断 | 不能仅此确定是温度、线材、某个FPGA原语或某条颜色通道 |
| 相机有彩点，灰度图干净 | 查相机/DDR数据路径，同时保留HDMI对特定图像数据模式敏感的可能 | 不能直接判为传感器噪声，也不能排除HDMI物理层 |
| 两种都干净 | 暂未复现，继续保留间歇性问题记录 | 不能宣布修复或长期稳定 |
| 图案正常但相机无图/错误灯亮 | 先查本次启动、捕获、DDR或错误状态 | 图案正常不等于完整视觉链路通过 |

温度尚未测量。长时间断电后短暂正常是已有用户观察，既可能与温度有关，也可能涉及复位、供电或运行状态；本测试不把它直接归因为过热。
