# FPGA ↔ RK 接口约定 v1（D2 任务 2.7，与队友冻结后填实）

> **2026-10-16整合入口：** 非压缩候选字段及向量已有`parallel/frame/frame_contract.py`，采用范围见[整合记录](../../../docs/DeepSeek独立检测与现行方案整合_2026-10-16.md)。本表仍未冻结；旧“1=LZ77”占位不能当正式枚举。压缩主线为BPR1，传输adapter、codec枚举/版本、CRC范围与严格拒收待共同确认；不能直接用当前RAW解析器解压缩payload。

> 状态：**草案** —— 与 RK 队友确认后把每项填实，改名为 `interface_v1_frozen.md`
> 2026-10-12当前边界：用户已选择RAW10主线，RAW12封存；960×540 Gray8是当前DDR/HDMI调试支路，不能默认当正式RK/NPU输入。目标双1080p30 RAW10 packed的裁剪/Bayer相位/stride及RK软件ISP交付仍未冻结。下表空项属于真实交付缺口，不能用于宣称整链路已可集成。见[审查响应](../../../docs/审查响应与返工_2026-10-12.md)。
