1. 从捕获字节流**自行定位并 inflate** zlib 流（Python 标准 zlib，独立解压器）：三例均 `eof` 正常、精确消耗 19 / 106 / 40032 B、无剩余、无多余尾字节（总长 63 / 150 / 40076 = 44 B 帧头 + stream）。

3. **四个 CRC 全部独立复算通过**：
   - header CRC：`crc32(header[0:40]) == slot40`（`76c03b59` / `37230343` / `ada898ad`）；
   - stream CRC：`crc32(捕获字节流) == slot36`（`75fe1a23` / `28302afc` / `30e190fe`）；
   - xform CRC：`crc32(解压结果) == slot32`（`560f7a8d` / `103ef251` / `c1a506b2`）；
   - raw CRC：`slot28` 恰等于**我方独立参考生成器**算出的整帧 raw CRC（`29929ca5` / `50cae326` / `1d2af67a`，`hdr.find()` 均精确落在偏移 28）——即 DUT 内部 raw 与独立参考逐样本一致（CRC32 精确相等，三套不同几何）。
4. 参考生成器按 tb 的 `smp(y,x)=(3x+5y+((x^y)&7)*17)&1023` 与 ROI 偏移、MIPI RAW10（4×MSB + 1×LSB 打包，`msb_first`）重建；换用 `lsb_first` 打包得到不同 CRC，会被本判据判负，说明该判据能区分目标缺陷。负对照：与错误参考比对时 8×2 出现 16/20、64×8 568/640、整帧 2.3 M 字节差异，判据具备敏感性。
