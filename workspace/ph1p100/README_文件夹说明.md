1. [FPGA 主线学习手册](当前必读/01_FPGA主线学习手册_由浅入深.md)：建立完整链路的理解，初次可先读 1–5 章。
2. [FPGA 独立开发路线与工作包](当前必读/02_FPGA独立开发路线与工作包.md)：了解 F0–F10 的步骤、交付与验收。
3. [单相机连接与首次调试](docs/相机主线_第一步连接与调试.md)：按 A 路单相机步骤动手。
4. [当前相机 DDR 验证记录](docs/相机DDR真实帧_操作与预期_2026-10-11.md)：查看已记录结果、复测方法与下一步。

已完成的 D1 / D2 实操见[历史实操入口](参考资料/历史实操/README.md)，无需重复安装工具或重做已成功例程。
