# FPGA Stereo Vision

基于安路 PH1P100 与 RK3588 的双目视觉竞赛项目，包含 FPGA 源码、验证脚本和设计文档。

[当前进展](#当前进展) · [快速开始](#快速开始) · [仓库结构](#仓库结构) · [文档导航](#文档导航)

## 项目概述

项目面向双路 IMX415 图像采集、FPGA 预处理与压缩、PCIe 传输，以及 RK3588 端的 ISP、NPU 推理、双目标定、匹配和深度重建。

```text
双路 IMX415 → FPGA 接收 / 预处理 / 压缩 / 缓存 → PCIe → RK3588 ISP / NPU / 双目深度
```

首个完整链路目标为 **双路 1920×1080、每路 30 fps**。更高分辨率与帧率依据实际测量推进；以上为研发目标，当前完成情况见下表。
